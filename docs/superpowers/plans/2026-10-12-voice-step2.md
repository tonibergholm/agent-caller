# Voice Step 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build voice delivery step 2 (spec §11 item 2): a spike on the real signed bundle, then a Swift bridge for capture and on-device transcription, the hold-key event tap and the toggle shortcut, the §6.2 recording rules, the §6.4 permissions, and a HUD Listening state, so that a spoken phrase reaches the step-1 fast path.

**Architecture:** The rules stay in plain Rust that Linux CI tests. `acd-voice` gains `listen.rs`: the trigger events, the hold-key state, the recorder state machine (60 s cap, short and silent utterances, generation filtering, final timeout) and the `SpeechInput` trait with a fake. The executor gains a press-time `listen` and a `resume`. `acd-voice-client`'s controller freezes the snapshot at the press, drives a `SpeechInput`, and feeds the final transcript into the same utterance path that typed text uses. In the app, a Swift package (`app/src-tauri/swift`) is compiled into a static library with a hand-written C ABI. Swift owns AVAudioEngine, SpeechAnalyzer and SpeechTranscriber, the event tap and the lock and sleep observers. Audio never leaves Swift. Rust gets typed events through one `'static` callback into a bounded queue.

**Tech Stack:** Rust 2024 (workspace `rust-version = "1.90"`), tokio; Swift 6.4 toolchain with Swift 5 language mode, SwiftPM, XCTest; AVFoundation, Speech (SpeechAnalyzer, SpeechTranscriber, AssetInventory; macOS 26), CoreGraphics event taps, IOKit HID access checks; `swift-rs = "=1.0.8"` as a build dependency only; Tauri 2.12.1, tauri-nspanel 2.1.1, tauri-plugin-global-shortcut 2.4.0; Svelte 5, vitest 5.

**Spec:** `docs/superpowers/specs/2026-10-11-voice-design.md` (authoritative), mainly §3, §4.1, §4.2, §4.4, §6.2, §6.3, §6.4, §8, §9, §10. Read the step-1 plan `docs/superpowers/plans/2026-10-11-voice-step1.md` for D1–D25, which still hold. This plan's decisions are numbered S1, S2, … so they never collide with step 1's.

## Review Focus

1. **The key-up is lost** (the tap missed it, the app was busy, or the key stuck). The microphone stops at 60 s, the recording is thrown away, and nothing is routed. Pinned in Task 2 (`a_recording_past_60_s_is_cut_and_discarded`) and Task 4 (`the_cap_stops_the_microphone_and_sends_nothing`).
2. **The user types with the hold key held** (Right Option + e types "é"). The recording is cancelled, nothing is routed, and the later key-up neither stops nor routes anything. 3. **The trigger is pressed during a voice countdown, then the user says "cancel".** The countdown is cancelled at the press, before any audio is transcribed. The HUD then says "Cancelled", not "Nothing to cancel". A press that is too short says "Cancelled" too. 4. **A late result from an older recording** (cancelled, replaced, or past the cap). It is dropped and never routed, in Swift and in Rust. Pinned in Task 2 (`events_from_an_older_session_are_dropped`), Task 4 (`a_late_final_from_a_cancelled_recording_routes_nothing`) and Task 5 (`testSessionEventsOfAnotherGenerationAreDropped`).

Pinned in Task 4 (`screen_lock_cancels_the_recording`, `voice_off_mid_recording_stops_the_microphone`) and Task 2 (`hold_reset_while_held_cancels`).

## Decisions made in this plan

Task text refers to these by number. Step-1 decisions D1–D25 still hold.

- **S1. The bridge is a C ABI static library. `swift-rs` only builds and links it.**
  - `app/src-tauri/swift` is a SwiftPM package with a `.static` library product `VoiceBridge`. Its Swift functions are exported with `@_cdecl`. A header-only C target, `VoiceBridgeC`, holds the contract (`voice_bridge.h`), so Swift compiles against the same struct and constants that Rust mirrors.
  - `build.rs` calls `swift_rs::SwiftLinker::new("13.0").with_package("VoiceBridge", "swift").link()`. swift-rs 1.0.8 is already in `app/src-tauri/Cargo.lock` through Tauri, so the build adds no new crate version. It handles the Swift runtime search paths and two Xcode 27 quirks: SwiftPM's changed product layout, and `@_cdecl` symbols that become local in static products (`globalize_cdecl_symbols`).
  - swift-rs's runtime types (`SRString`, `SRObject`) are not used. §4.2 needs callbacks from tasks that Swift owns, tagged with a generation. A function pointer and a plain struct do that with no reference counts crossing the boundary.
- **S2. Audio stays in Swift, and Rust sees one `SpeechInput` seam (spec deviation, see "Spec issues found").**
  - SpeechAnalyzer consumes AVAudioEngine buffers in the same process. Sending frames through Rust would add a copy per buffer and a path where the audio thread waits on Rust.
  - Inside Swift, `Capture` (AVAudioEngine) and `Transcription` (SpeechAnalyzer) are separate types, so XCTest can drive `Transcription` from a file.
  - Backend B can implement `SpeechInput` by combining `cpal` and `transcribe-rs` behind it.
- **S3. The session handle is a `u64` generation, not a pointer. There is one callback sink for the life of the process.**
  - Rust passes the generation to `vb_session_start`, `vb_session_stop` and `vb_session_cancel`. Swift holds at most one live session. Stop and cancel for any other generation do nothing.
  - `vb_init` is called once, with a `'static` Rust function and a null context. There is no context to free, so no callback can outlive its target.
  - Text in an event is a borrowed UTF-8 pointer, valid only during the callback. Rust copies it before returning.
- **S4. Swift processes commands in order through one bounded queue.** The C entry points yield commands into an `AsyncStream` with `.bufferingOldest(64)`. One task (`Runner`, an actor) consumes them in order and owns the session. A full queue drops the command and reports `VB_ERR_BUSY`. Stop and cancel never wait for a session to finish, so a cancel is never stuck behind a finishing transcript.
- **S5. One bounded queue from Swift to Rust; losing a terminal event fails closed.**
  - The Rust callback calls `try_send` on a tokio `mpsc::channel(64)` and never blocks. Swift calls it from one serial queue, never from the audio thread.
  - Partial text is coalesced in Swift to at most one event per 100 ms, latest wins. When the Rust queue is full, a partial is dropped, since the next one replaces it.
  - A final, error or hold event that cannot be queued is counted and dropped. The recorder then fails closed: a missing final ends after `FINAL_TIMEOUT` (5 s) with "Speech recognition unavailable", and a missing key-up ends at the 60 s cap. Nothing is routed in either case.
- **S6. The snapshot freezes at the press.** Spec §4.3 says voice freezes the snapshot "when recording starts". `Controller::hold` and `Controller::toggle` read `panel_open` and freeze at the press. The transcript later routes against that snapshot. Typed text keeps freezing at submit (it has no press).
- **S7. What a press does to the step on screen** (spec §4.4, extended):
  - A voice countdown, or a countdown step not yet acknowledged (D22 `Presenting`), is cancelled at once. The next utterance's "cancel" then reports `Cancelled`, because the flag that `begin` reads survives until that utterance.
  - A step still thinking is dropped. Its route result arrives for an old utterance number and is ignored.
  - A step that waits for input (confirm, which-one) stays on screen under the Listening state (`Hud::Listening { over }`), read-only, so the user can see what "confirm" or "the second one" refers to. Its buttons are disabled while listening.
  - A step already fired keeps waiting for its outcome (step-1 final review B4).
- **S8. Ignored recordings restore the screen; failed recordings fail closed.**
  - Too short, silent, empty, or cancelled (chord, HUD Cancel, Esc): `Executor::resume` shows the step that waits again, or "Cancelled" if the press cancelled a countdown, or hides the HUD.
  - Microphone or speech errors, the 60 s cap and the final timeout: `Executor::listen_failed` shows the error and ends any step that waits. Nothing can then be confirmed off screen.
- **S9. A recording cut by the 60 s cap is discarded, never routed.** A stuck key and a 60 s monologue look the same, and a fast-path phrase in a long accidental recording would reach a countdown. Swift also stops on its own 1 s after the cap (`max_ms + 1000`), in case Rust is stuck.
- **S10. "Silent" means less than 150 ms of voiced audio** (`MIN_VOICED`). A buffer counts as voiced when its RMS is at least -45 dBFS. Swift measures `audio_ms` and `voiced_ms`, and Rust applies the rules (`judge`). The thresholds are constants, and the live check in Task 10 records whether they need tuning.
- **S11. A chord cancels, and the tap never forwards key codes.** The listen-only tap watches `flagsChanged` and `keyDown`. For the hold key it forwards down or up. For any other key it forwards only "another key", with no key code, so the app cannot log what is typed. Another key while the hold key is down cancels the recording, and the following key-up does nothing.
- **S12. Hold key and toggle shortcut settings.**
  - The hold key is one of Right Option (default), Left Option, Right Command, Right Control, Fn, or Off.
  - The toggle shortcut defaults to `Control+Alt+V`. It is refused if it equals the inbox hotkey, and the inbox hotkey is refused if it equals the toggle shortcut.
  - Both are active only while voice is on. The hold key also needs Input Monitoring; the toggle shortcut does not (spec §6.4).
- **S13. Deferred from spec §8 to later work, and said so in Settings:** Space as a hold key while the inbox panel is open; choosing a microphone device (the system default is used); choosing the speech language (English only: the system locale if it is an English locale SpeechTranscriber supports, else en-US); a level meter in the HUD; voice, rate and alert settings (step 4); the model setting (step 3).
- **S14. Speech Recognition permission is conditional on the spike.** By default the plan assumes the SpeechTranscriber path does not need it, because SpeechAnalyzer runs on-device. `voice::permissions::SPEECH_PERMISSION_REQUIRED` holds the spike's answer.
  - If the spike shows transcription fails, or prompts, while Speech Recognition is not granted, set it to `true`. Settings then shows the Speech Recognition row, turning voice on asks for it, and `vb_session_start` refuses with `VB_ERR_SPEECH_DENIED` until it is granted.
  - `NSSpeechRecognitionUsageDescription` is in `Info.plist` either way. Calling `SFSpeechRecognizer.requestAuthorization` without it ends the process.
- **S15. The utterance source is a log tag only.** `Source::{Typed, Speech}` appears in the `utterance routed` log line. `safety::Origin` (`Fast`, `Model`) is unchanged, and so is every confirmation level. Task 4 checks that a spoken "approve" produces the same HUD states and frames as a typed one.
- **S16. The build works without the macOS 26 SDK, and the app's minimum macOS becomes 13.0.**
  - SpeechAnalyzer code sits under `#if compiler(>=6.2)`, which ships with the macOS 26 SDK, and under `if #available(macOS 26.0, *)`. Older SDKs build a stub that reports `sdk_too_old`. If CI's `macos-latest` image still has an older Xcode, the app still builds there.
  - The Swift package targets macOS 13, and `tauri.conf.json` sets `bundle.macOS.minimumSystemVersion` to `"13.0"`, so the static library and the app agree on the deployment target. Tauri's default was 10.13. This is a product change for the user to accept: no current user runs below 13.
  - Swift 5 language mode keeps C callbacks and AVFoundation from raising Swift 6 `Sendable` errors. Shared state sits in actors or behind `NSLock`.
- **S17. Input Monitoring.** Swift reads its status with `IOHIDCheckAccess(kIOHIDRequestTypeListenEvent)`, the only call that separates "not asked" from "denied". It asks with `CGRequestListenEventAccess()`. Settings refreshes the status when its window gains focus, and the app retries the tap when the status turns to granted. If the spike shows the tap needs a relaunch after the grant, set `voice::permissions::TAP_NEEDS_RELAUNCH` to `true`. Settings then says "Quit and reopen Agent Caller to use the hold key" instead of retrying.
- **S18. Microphone indicators.**
  - The menu bar icon gets a red dot in its top-right corner while the microphone is live. `tray::render` draws the summary and the indicator together, so a view update never erases the dot.
  - The HUD shows its microphone mark in the Listening state.
  - macOS also shows its own orange microphone indicator.
  - The microphone counts as live from `start` until `stop`, `cancel` or the cap, because Swift stops the engine at `stop`, before the final transcript.
- **S19. Permission errors in the HUD can open System Settings.** The only panes that can be opened are three fixed `x-apple.systempreferences:` URLs (Microphone, Speech Recognition, Input Monitoring). Commands take a `PermissionKind` enum, never a URL.
- **S20. The probe stays behind the debug setting.** Task 1 adds "Run voice probe" to Settings, shown only while "Show the typed command field" is on. Its reports carry statuses, counts, timings and a `matched` flag, never a transcript. It stays after the spike as a diagnostic.
- **S21. Assets.** If the English speech model is not installed, voice is unavailable with `assets_missing`, and Settings offers "Download speech model". That calls `AssetInventory.assetInstallationRequest(supporting:)`. There is no "English until installed" fallback, because English is the only language (see "Spec issues found").
- **S22. Spike outcomes that change or stop the plan.** S14 and S17 cover the two permission questions. Three more:
  - **Grants reset after a rebuild with the same identity**, with a changed CDHash and an unchanged designated requirement. Stop before Task 5 and escalate to the orchestrator. Every later task assumes stable grants. The first suspects are the designated requirement and the bundle identifier.
  - **Live transcription fails in the bundle with every permission granted**, or the clip run fails too. Stop before Task 5 and escalate. Record the probe's error tags and the locales.
  - **Partials do not stream** (`partials: 0` while `matched: true`). Set `Caps.partialsStream` in `Commands.swift` (Task 5) to `false`, so Settings does not promise live text. Nothing else changes: the HUD already shows "Listening…" without text (spec §4.1). The default is `true`.

## Spec issues found

The spec cannot be built exactly as written in these places. Each one is reported here; the spec itself is not edited.

1. **§4.1 lists Trigger, Capture and Transcriber as traits in `acd-voice`.** Trigger is an event type here (`TriggerEvent`, plus the `Hold` state), not a trait. The sources (a Swift event tap, a Tauri global shortcut) push events into `Controller::hold` and `Controller::toggle`, and the rules are pure functions over those events, so no trait object is needed to test them. §4.1 also splits Capture and Transcriber into two traits, with audio frames crossing to Rust. For backend A, SpeechAnalyzer takes AVAudioEngine buffers in Swift, so this plan keeps audio in Swift and exposes one `SpeechInput` seam (S2). Swift still has separate `Capture` and `Transcription` types. Also, §4.1 asks backends to report "its audio format". `Capabilities.sample_rate` reports the analyzer's format, for information only.
2. **§4.2 says "Rust holds opaque session handles".** The handle here is a `u64` generation, not a pointer (S3). It meets the same goal, and Rust never frees anything Swift owns.
3. **§6.2 does not say what happens to a recording cut at 60 s.** This plan discards it (S9).
4. **§6.2 does not define "silent".** This plan uses less than 150 ms of audio at or above -45 dBFS (S10).
5. **§4.4 covers a press during a countdown, but not during confirm, which-one or thinking.** S7 decides those cases.
6. **§8 sets Space as a hold key while the inbox panel is open, but gives no default toggle shortcut.** Space is deferred, and the toggle defaults to `Control+Alt+V` (S12, S13).
7. **§9 says for missing speech assets: "offer the system download; English until installed".** With English as the only language, a missing English model leaves nothing to fall back to. Voice is unavailable until the download finishes (S21).
8. **§6.4 says each permission "is requested when voice is first turned on".** For Input Monitoring, `CGRequestListenEventAccess` only opens a system prompt that points to System Settings, and the grant may need a relaunch (S17, spike item).
9. **§6.3 says the HUD's last 5 utterances are cleared when the screen locks.** Step 1 did not build that history (D20), so locking only cancels the recording here.

```c
#ifndef VOICE_BRIDGE_H
#define VOICE_BRIDGE_H
/*
 * The C contract between the app (Rust: app/src-tauri/src/voice/bridge.rs)
 * and the Swift voice bridge. Voice spec §4.2; step-2 plan S1 to S5.
 *
 * Ownership and lifetime:
 * - Swift owns every framework object, Task and AsyncSequence. Rust holds
 *   only generation numbers, never pointers to Swift objects (S3).
 * - vb_init is called once. `on_event` must stay valid for the life of the
 *   process. Swift calls it from one serial queue, never from the audio
 *   thread, and never re-entrantly. It must not block.
 * - vb_event.text is borrowed UTF-8, not NUL-terminated, valid only during
 *   the call. NULL when text_len is 0. The callback copies it.
 * - Every function returns at once. Results arrive as events.
 * - Nothing in an event is an error message: errors are codes (spec §6.3).
 */
#include <stddef.h>
#include <stdint.h>

/* Return codes, and vb_event.code for VB_EV_ERROR and VB_EV_ASSETS. */
#define VB_OK 0
#define VB_ERR_MIC_DENIED 1
#define VB_ERR_MIC_UNAVAILABLE 2
#define VB_ERR_SPEECH_DENIED 3
#define VB_ERR_SPEECH_UNAVAILABLE 4
#define VB_ERR_ASSETS_MISSING 5
#define VB_ERR_BUSY 6
#define VB_ERR_FAILED 7
#define VB_ERR_INPUT_MONITORING_DENIED 8
#define VB_ERR_TAP_FAILED 9
#define VB_ERR_NOT_INITIALIZED 10

/* vb_event.kind, and what each kind sets. */
#define VB_EV_PARTIAL 1u      /* generation; text: the live transcript so far */
#define VB_EV_FINAL 2u        /* generation; text; audio_ms; voiced_ms; value: stop-to-final ms */
#define VB_EV_ERROR 3u        /* generation; code: VB_ERR_* */
#define VB_EV_CAPS 4u         /* code: VB_UA_*; value: streams partials (0/1); value2: sample rate; text: locale id */
#define VB_EV_PERMISSION 5u   /* code: VB_PERM_*; value: VB_PS_* */
#define VB_EV_HOLD 6u         /* value: 1 the hold key went down, 0 up */
#define VB_EV_OTHER_KEY 7u    /* another key went down; never says which (S11) */
#define VB_EV_TAP_DISABLED 8u /* code: 1 timeout, 2 user input; value: 1 if re-enabled */
#define VB_EV_SYSTEM 9u       /* code: VB_SYS_* */
#define VB_EV_ASSETS 10u      /* code: VB_OK or VB_ERR_* */
#define VB_EV_PROBE 11u       /* text: a JSON report with no transcript (Task 1) */

/* Permissions (vb_event.code for VB_EV_PERMISSION). */
#define VB_PERM_MICROPHONE 1u
#define VB_PERM_SPEECH 2u
#define VB_PERM_INPUT_MONITORING 3u

/* Permission states (vb_event.value for VB_EV_PERMISSION). */
#define VB_PS_NOT_DETERMINED 0u
#define VB_PS_GRANTED 1u
#define VB_PS_DENIED 2u
#define VB_PS_RESTRICTED 3u

/* Why speech is unavailable (vb_event.code for VB_EV_CAPS); 0 = available. */
#define VB_UA_NONE 0u
#define VB_UA_OS_TOO_OLD 1u
#define VB_UA_SDK_TOO_OLD 2u
#define VB_UA_TRANSCRIBER_UNSUPPORTED 3u
#define VB_UA_LOCALE_UNSUPPORTED 4u
#define VB_UA_ASSETS_MISSING 5u

/* System events (vb_event.code for VB_EV_SYSTEM). */
#define VB_SYS_SCREEN_LOCKED 1u
#define VB_SYS_WILL_SLEEP 2u
#define VB_SYS_SCREENS_SLEEP 3u

typedef struct vb_event {
    uint64_t generation; /* the session's generation; 0 when not a session event */
    uint32_t kind;
    uint32_t code;
    uint32_t value;
    uint32_t value2;
    const uint8_t *text;
    size_t text_len;
    uint64_t audio_ms;
    uint64_t voiced_ms;
} vb_event;

typedef void (*vb_event_fn)(void *ctx, const vb_event *event);

/* Installs the callback and starts the bridge. VB_OK, or VB_ERR_FAILED if
 * on_event is NULL. A second call replaces nothing and returns VB_OK. */
int32_t vb_init(void *ctx, vb_event_fn on_event);

/* Task 1 spike probe; the report arrives as VB_EV_PROBE. */
void vb_probe_run(uint32_t step);
```

`app/src-tauri/swift/Sources/VoiceBridge/Bridge.swift`:

```swift
import Foundation
import VoiceBridgeC

/// A Swift copy of a `vb_event`. `deliver` lends it to C for one call.
struct Event: Equatable {
    var generation: UInt64 = 0
    var kind: UInt32
    var code: UInt32 = 0
    var value: UInt32 = 0
    var value2: UInt32 = 0
    var text: String? = nil
    var audioMs: UInt64 = 0
    var voicedMs: UInt64 = 0
}

/// The one way out of Swift (plan S3, S5). Every event goes through
/// `events`, a serial queue, so the Rust callback never runs twice at once
/// and never on the audio thread.
final class Bridge: @unchecked Sendable {
    static let shared = Bridge()

    let events = DispatchQueue(label: "dev.agentcaller.voice.events")
    private let lock = NSLock()
    private var sink: ((Event) -> Void)?
    private var current: UInt64 = 0

    func install(_ sink: @escaping (Event) -> Void) {
        lock.lock()
        self.sink = sink
        lock.unlock()
    }

    /// The live session; session events of any other generation are
    /// dropped (spec §4.2). 0 means no session.
    func setCurrent(_ generation: UInt64) {
        lock.lock()
        current = generation
        lock.unlock()
    }

    var currentGeneration: UInt64 {
        lock.lock()
        defer { lock.unlock() }
        return current
    }

    /// An event of session `e.generation`: dropped unless it is the live one.
    func emitSession(_ e: Event) {
        events.async {
            guard e.generation != 0, e.generation == self.currentGeneration else { return }
            self.deliver(e)
        }
    }

    /// An event not tied to a session.
    func emit(_ e: Event) {
        events.async { self.deliver(e) }
    }

    private func deliver(_ e: Event) {
        lock.lock()
        let sink = self.sink
        lock.unlock()
        sink?(e)
    }
}

private let started = NSLock()
private var isStarted = false

@_cdecl("vb_init")
public func vb_init(_ ctx: UnsafeMutableRawPointer?, _ onEvent: vb_event_fn?) -> Int32 {
    guard let onEvent else { return VB_ERR_FAILED }
    started.lock()
    defer { started.unlock() }
    if isStarted { return VB_OK }
    isStarted = true
    let context = UInt(bitPattern: ctx)
    Bridge.shared.install { e in
        var ev = vb_event()
        ev.generation = e.generation
        ev.kind = e.kind
        ev.code = e.code
        ev.value = e.value
        ev.value2 = e.value2
        ev.audio_ms = e.audioMs
        ev.voiced_ms = e.voicedMs
        let ctx = UnsafeMutableRawPointer(bitPattern: context)
        guard var text = e.text, !text.isEmpty else {
            onEvent(ctx, &ev)
            return
        }
        // Borrowed for this call only (header contract).
        text.withUTF8 { bytes in
            ev.text = bytes.baseAddress
            ev.text_len = bytes.count
            onEvent(ctx, &ev)
        }
    }
    return VB_OK
}
```

```swift
import AVFoundation

/// The three permissions voice may need (spec §6.4).
enum Permissions {
    static func status(_ permission: UInt32) -> UInt32 {
        switch permission {
        case VB_PERM_MICROPHONE:
            switch AVCaptureDevice.authorizationStatus(for: .audio) {
            case .authorized: return VB_PS_GRANTED
            case .denied: return VB_PS_DENIED
            case .restricted: return VB_PS_RESTRICTED
            default: return VB_PS_NOT_DETERMINED
            }
        case VB_PERM_SPEECH:
            switch SFSpeechRecognizer.authorizationStatus() {
            case .authorized: return VB_PS_GRANTED
            case .denied: return VB_PS_DENIED
            case .restricted: return VB_PS_RESTRICTED
            default: return VB_PS_NOT_DETERMINED
            }
        case VB_PERM_INPUT_MONITORING:
            // The only call that tells "never asked" from "denied" (plan S17).
            switch IOHIDCheckAccess(kIOHIDRequestTypeListenEvent) {
            case kIOHIDAccessTypeGranted: return VB_PS_GRANTED
            case kIOHIDAccessTypeDenied: return VB_PS_DENIED
            default: return VB_PS_NOT_DETERMINED
            }
        default:
            return VB_PS_NOT_DETERMINED
        }
    }

    /// Shows the system prompt if the user was never asked. The result
    /// arrives as VB_EV_PERMISSION.
    static func request(_ permission: UInt32) {
        let report = { Bridge.shared.emit(Event(kind: VB_EV_PERMISSION, code: permission, value: status(permission))) }
        switch permission {
        case VB_PERM_MICROPHONE:
            AVCaptureDevice.requestAccess(for: .audio) { _ in report() }
        case VB_PERM_SPEECH:
            // Needs NSSpeechRecognitionUsageDescription, or the process ends.
            SFSpeechRecognizer.requestAuthorization { _ in report() }
        case VB_PERM_INPUT_MONITORING:
            _ = CGRequestListenEventAccess()
            report()
        default:
            break
        }
    }
}

func permissionName(_ state: UInt32) -> String {
    switch state {
    case VB_PS_GRANTED: return "granted"
    case VB_PS_DENIED: return "denied"
    case VB_PS_RESTRICTED: return "restricted"
    default: return "not_determined"
    }
}
```

```swift
import AVFoundation

enum Audio {
    /// A buffer counts as voiced at or above this RMS level (plan S10).
    static let voicedDBFS: Float = -45

    /// Converts one capture buffer to the analyzer's format; nil on failure.
    static func convert(_ buffer: AVAudioPCMBuffer, with converter: AVAudioConverter, to format: AVAudioFormat) -> AVAudioPCMBuffer? {
        let ratio = format.sampleRate / buffer.format.sampleRate
        let capacity = AVAudioFrameCount((Double(buffer.frameLength) * ratio).rounded(.up)) + 16
        guard let out = AVAudioPCMBuffer(pcmFormat: format, frameCapacity: capacity) else { return nil }
        var fed = false
        var error: NSError?
        let status = converter.convert(to: out, error: &error) { _, inputStatus in
            if fed {
                inputStatus.pointee = .noDataNow
                return nil
            }
            fed = true
            inputStatus.pointee = .haveData
            return buffer
        }
        return status == .error || error != nil ? nil : out
    }

    /// RMS level of the first channel in dBFS; -infinity for silence or a
    /// format without float samples.
    static func levelDBFS(_ buffer: AVAudioPCMBuffer) -> Float {
        guard let data = buffer.floatChannelData, buffer.frameLength > 0 else { return -.infinity }
        let n = Int(buffer.frameLength)
        var sum: Float = 0
        for i in 0..<n {
            let s = data[0][i]
            sum += s * s
        }
        return sum > 0 ? 10 * log10(sum / Float(n)) : -.infinity
    }
}
```

```swift
import AVFoundation
import CoreGraphics
import Foundation
import Speech
import VoiceBridgeC

/// The step-2 spike (plan Task 1). A report carries statuses, counts,
/// timings and a `matched` flag; never a transcript (spec §3.7).
enum Probe {
    static func run(_ step: UInt32) {
        Task.detached {
            var report: [String: Any]
            switch step {
            case 1: report = await status()
            case 2: report = await ask(VB_PERM_MICROPHONE)
            case 3: report = await live(seconds: 4)
            case 4: report = await clip()
            case 5: report = await ask(VB_PERM_SPEECH)
            case 6: report = await inputMonitoring(seconds: 10)
            default: report = ["error": "unknown_step"]
            }
            report["step"] = Int(step)
            let data = try? JSONSerialization.data(withJSONObject: report, options: [.sortedKeys])
            let json = data.flatMap { String(data: $0, encoding: .utf8) } ?? "{}"
            Bridge.shared.emit(Event(kind: VB_EV_PROBE, text: json))
        }
    }

    static func ms(since start: ContinuousClock.Instant) -> Int {
        let d = start.duration(to: .now).components
        return Int(d.seconds) * 1000 + Int(d.attoseconds / 1_000_000_000_000_000)
    }

    static func permissions() -> [String: Any] {
        [
            "microphone": permissionName(Permissions.status(VB_PERM_MICROPHONE)),
            "speech": permissionName(Permissions.status(VB_PERM_SPEECH)),
            "input_monitoring": permissionName(Permissions.status(VB_PERM_INPUT_MONITORING)),
        ]
    }

    static func status() async -> [String: Any] {
        var r = permissions()
        r["bundle"] = Bundle.main.bundleIdentifier ?? "none"
        r["os"] = ProcessInfo.processInfo.operatingSystemVersionString
        r["mic_usage_string"] = Bundle.main.object(forInfoDictionaryKey: "NSMicrophoneUsageDescription") != nil
        r["speech_usage_string"] = Bundle.main.object(forInfoDictionaryKey: "NSSpeechRecognitionUsageDescription") != nil
        #if compiler(>=6.2)
        if #available(macOS 26.0, *) {
            r["transcriber_available"] = SpeechTranscriber.isAvailable
            let english = { (l: Locale) in l.language.languageCode?.identifier == "en" }
            r["supported_count"] = await SpeechTranscriber.supportedLocales.count
            r["supported_en"] = await SpeechTranscriber.supportedLocales.filter(english).map { $0.identifier }.sorted()
            r["installed_en"] = await SpeechTranscriber.installedLocales.filter(english).map { $0.identifier }.sorted()
            r["resolved_locale"] = await Locales.resolve()?.identifier ?? "none"
        } else {
            r["reason"] = "os_too_old"
        }
        #else
        r["reason"] = "sdk_too_old"
        #endif
        return r
    }

    static func ask(_ permission: UInt32) async -> [String: Any] {
        let before = permissionName(Permissions.status(permission))
        await withCheckedContinuation { (done: CheckedContinuation<Void, Never>) in
            switch permission {
            case VB_PERM_MICROPHONE: AVCaptureDevice.requestAccess(for: .audio) { _ in done.resume() }
            case VB_PERM_SPEECH: SFSpeechRecognizer.requestAuthorization { _ in done.resume() }
            default: done.resume()
            }
        }
        return ["before": before, "after": permissionName(Permissions.status(permission))]
    }

    /// Speak "approve the request" right after starting. Measures partials
    /// and the time from stop to the final text. Speech Recognition is
    /// neither asked nor checked first: this run decides S14.
    static func live(seconds: Double) async -> [String: Any] {
        #if compiler(>=6.2)
        guard #available(macOS 26.0, *) else { return ["error": "os_too_old"] }
        var r = permissions()
        guard let locale = await Locales.resolve() else { return r.merging(["error": "no_locale"]) { $1 } }
        let transcriber = SpeechTranscriber(locale: locale, transcriptionOptions: [], reportingOptions: [.volatileResults], attributeOptions: [])
        let analyzer = SpeechAnalyzer(modules: [transcriber])
        guard let format = await SpeechAnalyzer.bestAvailableAudioFormat(compatibleWith: [transcriber]) else {
            return r.merging(["error": "no_format"]) { $1 }
        }
        let engine = AVAudioEngine()
        let input = engine.inputNode
        let micFormat = input.outputFormat(forBus: 0)
        guard micFormat.sampleRate > 0, let converter = AVAudioConverter(from: micFormat, to: format) else {
            return r.merging(["error": "no_microphone"]) { $1 }
        }
        let (inputs, feed) = AsyncStream.makeStream(of: AnalyzerInput.self, bufferingPolicy: .bufferingNewest(64))
        // The probe converts on the audio thread; Task 5 does not.
        input.installTap(onBus: 0, bufferSize: 4096, format: micFormat) { buffer, _ in
            if let out = Audio.convert(buffer, with: converter, to: format) { feed.yield(AnalyzerInput(buffer: out)) }
        }
        let started = ContinuousClock.now
        let reader = Task { () -> (Int, Int, String, String) in
            var partials = 0
            var first = -1
            var text = ""
            do {
                for try await result in transcriber.results {
                    if result.isFinal {
                        text += String(result.text.characters)
                    } else {
                        partials += 1
                        if first < 0 { first = ms(since: started) }
                    }
                }
            } catch {
                return (partials, first, text, "results_failed")
            }
            return (partials, first, text, "none")
        }
        do {
            try await analyzer.start(inputSequence: inputs)
            try engine.start()
        } catch {
            input.removeTap(onBus: 0)
            return r.merging(["error": "start_failed"]) { $1 }
        }
        try? await Task.sleep(for: .seconds(seconds))
        let stopped = ContinuousClock.now
        engine.stop()
        input.removeTap(onBus: 0)
        feed.finish()
        do {
            try await analyzer.finalizeAndFinishThroughEndOfInput()
        } catch {
            return r.merging(["error": "finalize_failed"]) { $1 }
        }
        let (partials, first, text, error) = await reader.value
        r["locale"] = locale.identifier
        r["partials"] = partials
        r["first_partial_ms"] = first
        r["final_latency_ms"] = ms(since: stopped)
        r["final_chars"] = text.count
        r["matched"] = text.lowercased().contains("approve")
        r["error"] = error
        r["speech_after"] = permissionName(Permissions.status(VB_PERM_SPEECH))
        return r
        #else
        return ["error": "sdk_too_old"]
        #endif
    }

    /// A clip made with `say`: a repeatable baseline next to the live run.
    static func clip() async -> [String: Any] {
        #if compiler(>=6.2)
        guard #available(macOS 26.0, *) else { return ["error": "os_too_old"] }
        let url = FileManager.default.temporaryDirectory.appendingPathComponent("agent-caller-probe.aiff")
        let say = Process()
        say.executableURL = URL(fileURLWithPath: "/usr/bin/say")
        say.arguments = ["-o", url.path, "approve the request"]
        do {
            try say.run()
            say.waitUntilExit()
        } catch {
            return ["error": "say_failed"]
        }
        guard let locale = await Locales.resolve() else { return ["error": "no_locale"] }
        let transcriber = SpeechTranscriber(locale: locale, transcriptionOptions: [], reportingOptions: [], attributeOptions: [])
        let started = ContinuousClock.now
        do {
            let file = try AVAudioFile(forReading: url)
            async let text = transcriber.results.reduce("") { $0 + String($1.text.characters) }
            let analyzer = SpeechAnalyzer(modules: [transcriber])
            if let last = try await analyzer.analyzeSequence(from: file) {
                try await analyzer.finalizeAndFinish(through: last)
            } else {
                await analyzer.cancelAndFinishNow()
            }
            let t = try await text
            return ["elapsed_ms": ms(since: started), "final_chars": t.count, "matched": t.lowercased().contains("approve"),
                    "speech_after": permissionName(Permissions.status(VB_PERM_SPEECH))]
        } catch {
            return ["error": "transcription_failed", "elapsed_ms": ms(since: started),
                    "speech_after": permissionName(Permissions.status(VB_PERM_SPEECH))]
        }
        #else
        return ["error": "sdk_too_old"]
        #endif
    }

    /// Asks for Input Monitoring, then counts Right Option presses for
    /// `seconds` with a listen-only flagsChanged tap. Hold Right Option
    /// three times. Only that key is counted; nothing else is recorded.
    static func inputMonitoring(seconds: Double) async -> [String: Any] {
        let before = permissionName(Permissions.status(VB_PERM_INPUT_MONITORING))
        let requested = CGRequestListenEventAccess()
        let counts = await FlagCounter().run(seconds: seconds)
        return ["before": before, "request_returned": requested, "tap_created": counts.created,
                "right_option_down": counts.down, "right_option_up": counts.up,
                "after": permissionName(Permissions.status(VB_PERM_INPUT_MONITORING))]
    }
}

/// A probe-only tap on its own thread and run loop.
final class FlagCounter: @unchecked Sendable {
    var down = 0
    var up = 0

    func run(seconds: Double) async -> (created: Bool, down: Int, up: Int) {
        await withCheckedContinuation { done in
            let thread = Thread {
                let mask = CGEventMask(1 << CGEventType.flagsChanged.rawValue)
                let me = Unmanaged.passUnretained(self).toOpaque()
                let callback: CGEventTapCallBack = { _, type, event, info in
                    if type == .flagsChanged, event.getIntegerValueField(.keyboardEventKeycode) == 61, let info {
                        let counter = Unmanaged<FlagCounter>.fromOpaque(info).takeUnretainedValue()
                        if event.flags.rawValue & 0x40 != 0 { counter.down += 1 } else { counter.up += 1 }
                    }
                    return Unmanaged.passUnretained(event)
                }
                guard let tap = CGEvent.tapCreate(tap: .cgSessionEventTap, place: .headInsertEventTap, options: .listenOnly,
                                                  eventsOfInterest: mask, callback: callback, userInfo: me) else {
                    done.resume(returning: (false, 0, 0))
                    return
                }
                let source = CFMachPortCreateRunLoopSource(nil, tap, 0)
                CFRunLoopAddSource(CFRunLoopGetCurrent(), source, .commonModes)
                CGEvent.tapEnable(tap: tap, enable: true)
                _ = CFRunLoopRunInMode(.defaultMode, seconds, false)
                CGEvent.tapEnable(tap: tap, enable: false)
                CFMachPortInvalidate(tap)
                done.resume(returning: (true, self.down, self.up))
            }
            thread.start()
        }
    }
}

@_cdecl("vb_probe_run")
public func vb_probe_run(_ step: UInt32) {
    Probe.run(step)
}
```

```rust
/// What the bridge reported, copied out of the callback. `Debug` shows no
/// voice text: transcripts are `VoiceText` (Task 6).
#[derive(Debug, PartialEq)]
pub enum BridgeEvent {
    /// A spike report: statuses, counts and timings, no transcript.
    Probe(String),
}

/// The queue from the callback to the app (plan S5).
pub const QUEUE: usize = 64;
static TX: OnceLock<mpsc::Sender<BridgeEvent>> = OnceLock::new();
/// Events dropped because the queue was full.
pub static DROPPED: AtomicU64 = AtomicU64::new(0);

/// Copies `ev` into an owned event; `None` for kinds the app ignores.
///
/// # Safety
/// `ev.text` is null, or points to `ev.text_len` readable bytes for the
/// duration of this call (header contract).
pub unsafe fn decode(ev: &VbEvent) -> Option<BridgeEvent> {
    let text = || {
        if ev.text.is_null() || ev.text_len == 0 {
            return String::new();
        }
        // SAFETY: the caller guarantees `text_len` readable bytes.
        let bytes = unsafe { std::slice::from_raw_parts(ev.text, ev.text_len) };
        String::from_utf8_lossy(bytes).into_owned()
    };
    match ev.kind {
        VB_EV_PROBE => Some(BridgeEvent::Probe(text())),
        _ => None,
    }
}

/// Swift calls this from its event queue. It copies and never blocks.
unsafe extern "C" fn on_event(_ctx: *mut c_void, event: *const VbEvent) {
    // SAFETY: Swift passes a valid event for the duration of this call.
    let Some(ev) = (unsafe { event.as_ref() }) else {
        return;
    };
    // SAFETY: same contract for the text it points to.
    let Some(decoded) = (unsafe { decode(ev) }) else {
        return;
    };
    if let Some(tx) = TX.get()
        && tx.try_send(decoded).is_err()
    {
        DROPPED.fetch_add(1, Ordering::Relaxed);
    }
}

/// Starts the bridge once. `None` if it was started before or failed.
pub fn start() -> Option<mpsc::Receiver<BridgeEvent>> {
    let (tx, rx) = mpsc::channel(QUEUE);
    TX.set(tx).ok()?;
    // SAFETY: `on_event` is a 'static function and the context is unused (S3).
    let code = unsafe { ffi::vb_init(std::ptr::null_mut(), on_event) };
    if code != VB_OK {
        tracing::error!(code, "the voice bridge did not start");
        return None;
    }
    Some(rx)
}

/// Runs spike probe `step` (Task 1); the report arrives as `Probe`.
pub fn probe(step: u32) {
    // SAFETY: takes a plain integer; returns at once.
    unsafe { ffi::vb_probe_run(step) }
}
```

```rust
//! Triggers and recording rules (voice spec §4.1, §6.2). Plain Rust with
//! the time passed in, so every rule is tested on Linux. The platform sits
//! behind `SpeechInput`; on macOS the app implements it over the Swift
//! bridge, where the audio stays (step-2 plan S2).
use std::time::{Duration, Instant};

use serde::Serialize;

use crate::text::VoiceText;

/// Spec §6.2: a lost key-up must not leave the microphone on.
pub const MAX_RECORDING: Duration = Duration::from_secs(60);
/// Spec §6.2: shorter utterances are ignored.
pub const MIN_UTTERANCE: Duration = Duration::from_millis(300);
/// Less voiced audio than this is silent (plan S10).
pub const MIN_VOICED: Duration = Duration::from_millis(150);
/// After a stop the final text must arrive within this, or the recording
/// fails closed (plan S5).
pub const FINAL_TIMEOUT: Duration = Duration::from_secs(5);

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct Limits {
    pub max: Duration,
    pub final_timeout: Duration,
}

impl Default for Limits {
    fn default() -> Self {
        Self { max: MAX_RECORDING, final_timeout: FINAL_TIMEOUT }
    }
}

/// What a trigger asks for (spec §4.1).
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum TriggerEvent {
    Start,
    Stop,
    Cancel,
}

/// The hold key (spec §6.2, plan S11). Down starts, up stops. Another key
/// while it is down is a chord (Option+e types "é"): that cancels, and the
/// following key-up does nothing.
#[derive(Debug, Default)]
pub struct Hold {
    down: bool,
    chorded: bool,
}

impl Hold {
    pub fn key(&mut self, down: bool) -> Option<TriggerEvent> {
        match (self.down, down) {
            (false, true) => {
                self.down = true;
                self.chorded = false;
                Some(TriggerEvent::Start)
            }
            (true, false) => {
                self.down = false;
                (!std::mem::take(&mut self.chorded)).then_some(TriggerEvent::Stop)
            }
            // Auto-repeat, or a release we never saw pressed.
            _ => None,
        }
    }

    pub fn other_key(&mut self) -> Option<TriggerEvent> {
        if self.down && !self.chorded {
            self.chorded = true;
            return Some(TriggerEvent::Cancel);
        }
        None
    }

    /// The tap was disabled or restarted, so a key-up may be lost.
    pub fn reset(&mut self) -> Option<TriggerEvent> {
        let held = self.down && !self.chorded;
        *self = Self::default();
        held.then_some(TriggerEvent::Cancel)
    }
}

/// The toggle shortcut: the first press starts, the second stops.
pub fn toggle(listening: bool) -> TriggerEvent {
    if listening { TriggerEvent::Stop } else { TriggerEvent::Start }
}

/// Why a recording could not start or went wrong. Classified only: no
/// platform error text crosses into Rust (spec §6.3).
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize)]
#[serde(rename_all = "snake_case")]
pub enum ListenError {
    MicrophoneDenied,
    MicrophoneUnavailable,
    SpeechDenied,
    SpeechUnavailable,
    AssetsMissing,
    Failed,
}

/// Why voice cannot listen on this machine (spec §9).
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize)]
#[serde(rename_all = "snake_case")]
pub enum Unavailable {
    /// The backend has not answered yet.
    Checking,
    NotMac,
    OsTooOld,
    /// Built without the macOS 26 SDK (plan S16).
    SdkTooOld,
    TranscriberUnsupported,
    LocaleUnsupported,
    AssetsMissing,
}

/// What a backend reports (spec §4.1).
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize)]
pub struct Capabilities {
    /// `None` when it can listen.
    pub unavailable: Option<Unavailable>,
    /// Without partials the HUD shows "Listening…" with no live text.
    pub streams_partials: bool,
    /// The analyzer's audio format, for information.
    pub sample_rate: u32,
}

impl Capabilities {
    pub const CHECKING: Self = Self { unavailable: Some(Unavailable::Checking), streams_partials: false, sample_rate: 0 };
}

/// From the platform. `generation` is the id `SpeechInput::start` got.
#[derive(Clone, Debug, PartialEq, Eq)]
pub enum ListenEvent {
    Partial { generation: u64, text: VoiceText },
    Final { generation: u64, text: VoiceText, audio: Duration, voiced: Duration },
    Error { generation: u64, error: ListenError },
}

impl ListenEvent {
    pub fn generation(&self) -> u64 {
        match self {
            ListenEvent::Partial { generation, .. }
            | ListenEvent::Final { generation, .. }
            | ListenEvent::Error { generation, .. } => *generation,
        }
    }
}

/// Capture and transcription (spec §4.1, one seam: plan S2). Every method
/// returns at once and never calls back synchronously; events arrive
/// later through `Controller::speech_event`.
pub trait SpeechInput: Send + Sync {
    fn capabilities(&self) -> Capabilities;
    /// Starts recording `generation`, stopping on its own after `max`
    /// (plus a margin). A live session of another generation is cancelled.
    fn start(&self, generation: u64, max: Duration) -> Result<(), ListenError>;
    /// Stops capture and finishes the transcript: a `Final` or an `Error`
    /// for `generation` follows.
    fn stop(&self, generation: u64);
    /// Stops capture and drops the session; nothing follows.
    fn cancel(&self, generation: u64);
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Ignored {
    TooShort,
    Silent,
    Empty,
}

/// How a recording ended.
#[derive(Clone, Debug, PartialEq, Eq)]
pub enum Heard {
    Transcript(VoiceText),
    Ignored(Ignored),
    Failed(ListenError),
    /// The 60 s cap: discarded (plan S9).
    TooLong,
    /// No final within `FINAL_TIMEOUT` after the stop.
    TimedOut,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub enum Progress {
    Partial(VoiceText),
    Done(Heard),
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Start {
    Started,
    /// A recording that was still finishing was dropped; cancel it.
    Replaced(u64),
    /// Already listening; the press changes nothing.
    Busy,
}

#[derive(Clone, Copy, Debug, Default, PartialEq, Eq)]
enum Phase {
    #[default]
    Idle,
    Listening { generation: u64, since: Instant },
    Finishing { generation: u64, since: Instant },
}

/// One recording at a time (spec §6.2). Events of any other generation
/// are dropped (spec §4.2).
#[derive(Debug, Default)]
pub struct Recorder {
    phase: Phase,
    limits: Limits,
}

impl Recorder {
    pub fn new(limits: Limits) -> Self {
        Self { phase: Phase::Idle, limits }
    }

    pub fn limits(&self) -> Limits {
        self.limits
    }

    /// The generation whose microphone is live.
    pub fn listening(&self) -> Option<u64> {
        match self.phase {
            Phase::Listening { generation, .. } => Some(generation),
            _ => None,
        }
    }

    /// Listening, or stopped and waiting for the final text.
    pub fn active(&self) -> Option<u64> {
        match self.phase {
            Phase::Listening { generation, .. } | Phase::Finishing { generation, .. } => Some(generation),
            Phase::Idle => None,
        }
    }

    pub fn start(&mut self, generation: u64, now: Instant) -> Start {
        let result = match self.phase {
            Phase::Listening { .. } => return Start::Busy,
            Phase::Finishing { generation: old, .. } => Start::Replaced(old),
            Phase::Idle => Start::Started,
        };
        self.phase = Phase::Listening { generation, since: now };
        result
    }

    /// The key went up or the toggle was pressed again.
    pub fn stop(&mut self, now: Instant) -> Option<u64> {
        let generation = self.listening()?;
        self.phase = Phase::Finishing { generation, since: now };
        Some(generation)
    }

    /// Drops the recording; nothing it produces is routed.
    pub fn cancel(&mut self) -> Option<u64> {
        let generation = self.active()?;
        self.phase = Phase::Idle;
        Some(generation)
    }

    /// The 60 s cap and the final timeout. The caller cancels the returned
    /// generation on the platform.
    pub fn tick(&mut self, now: Instant) -> Option<(u64, Heard)> {
        let (generation, heard) = match self.phase {
            Phase::Listening { generation, since } if now.duration_since(since) >= self.limits.max => (generation, Heard::TooLong),
            Phase::Finishing { generation, since } if now.duration_since(since) >= self.limits.final_timeout => {
                (generation, Heard::TimedOut)
            }
            _ => return None,
        };
        self.phase = Phase::Idle;
        Some((generation, heard))
    }

    pub fn event(&mut self, ev: ListenEvent) -> Option<Progress> {
        if self.active() != Some(ev.generation()) {
            return None;
        }
        match ev {
            ListenEvent::Partial { text, .. } => self.listening().map(|_| Progress::Partial(text)),
            ListenEvent::Final { text, audio, voiced, .. } => {
                self.phase = Phase::Idle;
                Some(Progress::Done(judge(text, audio, voiced)))
            }
            ListenEvent::Error { error, .. } => {
                self.phase = Phase::Idle;
                Some(Progress::Done(Heard::Failed(error)))
            }
        }
    }
}

/// Spec §6.2: under 0.3 s, silent (plan S10) or empty is ignored.
pub fn judge(text: VoiceText, audio: Duration, voiced: Duration) -> Heard {
    if audio < MIN_UTTERANCE {
        Heard::Ignored(Ignored::TooShort)
    } else if voiced < MIN_VOICED {
        Heard::Ignored(Ignored::Silent)
    } else if text.expose().trim().is_empty() {
        Heard::Ignored(Ignored::Empty)
    } else {
        Heard::Transcript(text)
    }
}
```

```rust
    /// The trigger was pressed (spec §4.4, step-2 plan S7). A voice
    /// countdown, or a countdown step not yet shown, is cancelled at once.
    /// A step still thinking is dropped. A step that waits for input
    /// (confirm, which-one) stays and is returned, to show under the
    /// Listening state. A fired step keeps waiting for its outcome.
    ///
    /// Returns the recording's id, from the counter every HUD input id
    /// comes from, so the HUD's Cancel can name it.
    pub fn listen(&mut self, port: &dyn InboxPort) -> (u64, Option<Hud>) {
        match std::mem::take(&mut self.state) {
            State::Counting { action_id, .. } if port.cancel(&action_id) => self.trigger_cancelled = true,
            // Not enqueued yet (D22): its acknowledgement now matches nothing.
            State::Presenting { .. } => self.trigger_cancelled = true,
            // Its route result now belongs to an old utterance.
            State::Thinking(_) => self.utterance += 1,
            other => self.state = other,
        }
        let over = match &self.state {
            State::Confirm { .. } | State::WhichOne(..) => Some(self.waiting().hud),
            _ => None,
        };
        (self.next_proposal(), over)
    }

    /// The recording ended with nothing to route: too short, silent,
    /// empty, or cancelled (plan S8). Shows what the press cancelled, or
    /// the step that waits, or a fired step's progress, or nothing.
    pub fn resume(&mut self) -> Reaction {
        if std::mem::take(&mut self.trigger_cancelled) {
            return self.done(None, OutcomeView::Cancelled);
        }
        match &self.state {
            State::Counting { proposal, .. } | State::Sending { proposal, .. } => {
                show(Hud::Sending { proposal: self.view(proposal), too_late_to_cancel: false })
            }
            _ => self.waiting(),
        }
    }

    /// Nothing waits, counts down, sends or thinks, so a notice may take
    /// the HUD without hiding a step (Task 4 `Controller::notice`).
    pub fn is_idle(&self) -> bool {
        matches!(self.state, State::Idle | State::Shown)
    }

    /// The recording failed: microphone, speech, the 60 s cap or the final
    /// timeout (plan S8). A step that waits ends too, so nothing can be
    /// confirmed off screen. A fired step keeps waiting for its outcome.
    pub fn listen_failed(&mut self, refusal: Refusal) -> Reaction {
        self.trigger_cancelled = false;
        if matches!(self.state, State::Counting { .. } | State::Sending { .. }) {
            return show(Hud::Error { refusal, transcript: None });
        }
        self.error(refusal)
    }
```

```rust
    pub fn speech_event(&self, ev: ListenEvent) {

        // Read before `event` moves the recorder to idle: the indicator goes

            return;
        }
        let Some(input) = self.input() else {
            return;

        if let Some(why) = input.capabilities().unavailable {
            tracing::info!(target: "acd_voice", reason = ?why, "voice cannot listen");
            let r = core.exec.listen_failed(Refusal::from(why));
            self.emit(&mut core.exec, r);
            return;

            self.sink.listening(false);
```

```swift
/// One capture buffer, measured in its own float format and converted to
/// the analyzer's format.
struct Chunk: @unchecked Sendable {
    let buffer: AVAudioPCMBuffer
    let seconds: Double
    let voiced: Bool

    static func make(_ buffer: AVAudioPCMBuffer, converter: AVAudioConverter, to format: AVAudioFormat) -> Chunk? {
        let voiced = Audio.levelDBFS(buffer) >= Audio.voicedDBFS
        guard let out = Audio.convert(buffer, with: converter, to: format) else { return nil }
        return Chunk(buffer: out, seconds: Double(buffer.frameLength) / buffer.format.sampleRate, voiced: voiced)
    }
}
```

```swift
import AVFoundation

/// The microphone (spec §4.1, Capture). The tap measures and converts one
/// buffer and yields it into a bounded stream. It takes no lock of ours and
/// never calls Rust (spec §4.2). Conversion in the tap follows Apple's
/// SpeechAnalyzer sample.
final class Capture: @unchecked Sendable {
    private let engine = AVAudioEngine()
    private var sink: AsyncStream<Chunk>.Continuation?
    private var observer: NSObjectProtocol?

    func start(to format: AVAudioFormat, onLost: @escaping @Sendable () -> Void) throws -> AsyncStream<Chunk> {
        let input = engine.inputNode
        let micFormat = input.outputFormat(forBus: 0)
        guard micFormat.sampleRate > 0, micFormat.channelCount > 0,
              let converter = AVAudioConverter(from: micFormat, to: format) else {
            throw BridgeError.micUnavailable
        }
        let (stream, sink) = AsyncStream.makeStream(of: Chunk.self, bufferingPolicy: .bufferingNewest(64))
        self.sink = sink
        input.installTap(onBus: 0, bufferSize: 4096, format: micFormat) { buffer, _ in
            if let chunk = Chunk.make(buffer, converter: converter, to: format) { sink.yield(chunk) }
        }
        // The device went away or changed (spec §9: "Microphone unavailable").
        observer = NotificationCenter.default.addObserver(forName: .AVAudioEngineConfigurationChange, object: engine, queue: nil) { _ in
            onLost()
        }
        engine.prepare()
        do {
            try engine.start()
        } catch {
            stop()
            throw BridgeError.micUnavailable
        }
        return stream
    }

    /// Releases the microphone and ends the stream. Safe to call twice.
    func stop() {
        if let observer {
            NotificationCenter.default.removeObserver(observer)
            self.observer = nil
        }
        engine.stop()
        engine.inputNode.removeTap(onBus: 0)
        sink?.finish()
        sink = nil
    }
}
```

```swift
import AVFoundation
import Foundation

/// How a recording ended, measured in Swift; Rust applies the rules (S10).
struct Heard: Sendable {
    let text: String
    let audioMs: UInt64
    let voicedMs: UInt64
    let latencyMs: UInt64
}

#if compiler(>=6.2)
import Speech

/// SpeechAnalyzer and SpeechTranscriber over a chunk stream (spec §4.1,
/// Transcriber). On-device only (spec §3.6).
@available(macOS 26.0, *)
actor Transcription {
    private let transcriber: SpeechTranscriber
    private let analyzer: SpeechAnalyzer
    private var feed: AsyncStream<AnalyzerInput>.Continuation?
    private var reader: Task<String, Error>?
    private var pump: Task<Void, Never>?
    private var audio: Double = 0
    private var voiced: Double = 0

    init(locale: Locale) {
        transcriber = SpeechTranscriber(locale: locale, transcriptionOptions: [], reportingOptions: [.volatileResults], attributeOptions: [])
        analyzer = SpeechAnalyzer(modules: [transcriber])
    }

    func format() async -> AVAudioFormat? {
        await SpeechAnalyzer.bestAvailableAudioFormat(compatibleWith: [transcriber])
    }

    /// Reads `chunks` until they end. `partial` gets the live text at most
    /// every 100 ms, latest wins (plan S5).
    func start(_ chunks: AsyncStream<Chunk>, partial: @escaping @Sendable (String) -> Void) async throws {
        let (inputs, feed) = AsyncStream.makeStream(of: AnalyzerInput.self, bufferingPolicy: .bufferingNewest(64))
        self.feed = feed
        let transcriber = self.transcriber
        reader = Task {
            var final = ""
            var last = ContinuousClock.now - .seconds(1)
            for try await result in transcriber.results {
                if result.isFinal {
                    final += String(result.text.characters)
                } else if last.duration(to: .now) >= .milliseconds(100) {
                    last = .now
                    partial(final + String(result.text.characters))
                }
            }
            return final
        }
        try await analyzer.start(inputSequence: inputs)
        pump = Task { await self.consume(chunks) }
    }

    private func consume(_ chunks: AsyncStream<Chunk>) async {
        for await chunk in chunks {
            audio += chunk.seconds
            if chunk.voiced { voiced += chunk.seconds }
            feed?.yield(AnalyzerInput(buffer: chunk.buffer))
        }
        feed?.finish()
    }

    /// Call after the chunk stream ended: the final text and measurements.
    func finish() async throws -> Heard {
        let stopped = ContinuousClock.now
        await pump?.value
        try await analyzer.finalizeAndFinishThroughEndOfInput()
        let text = try await reader?.value ?? ""
        return Heard(text: text, audioMs: UInt64(audio * 1000), voicedMs: UInt64(voiced * 1000),
                     latencyMs: UInt64(Probe.ms(since: stopped)))
    }

    func cancel() async {
        pump?.cancel()
        feed?.finish()
        reader?.cancel()
        await analyzer.cancelAndFinishNow()
    }
}
#endif
```

```swift
import Foundation
import VoiceBridgeC

/// One recording, owned by `Runner` (plan S3, S4).
protocol Session: AnyObject, Sendable {
    var generation: UInt64 { get }
    /// nil once capture runs; else a VB_ERR_* code.
    func start(maxMs: UInt32) async -> Int32?
    func finish() async
    func cancel() async
}

#if compiler(>=6.2)
/// Capture into Transcription (plan S2). Every event carries the
/// generation, and the bridge drops it unless it is still the live one.
@available(macOS 26.0, *)
actor LiveSession: Session {
    nonisolated let generation: UInt64
    private let capture = Capture()
    private let transcription: Transcription
    private var ended = false
    private var failsafe: Task<Void, Never>?

    init(generation: UInt64, locale: Locale) {
        self.generation = generation
        transcription = Transcription(locale: locale)
    }

    func start(maxMs: UInt32) async -> Int32? {
        guard let format = await transcription.format() else { return VB_ERR_SPEECH_UNAVAILABLE }
        let generation = self.generation
        do {
            let chunks = try capture.start(to: format) { [weak self] in
                Task { await self?.fail(VB_ERR_MIC_UNAVAILABLE) }
            }
            try await transcription.start(chunks) { text in
                Bridge.shared.emitSession(Event(generation: generation, kind: VB_EV_PARTIAL, text: text))
            }
        } catch let e as BridgeError {
            capture.stop()
            return e.code
        } catch {
            capture.stop()
            return VB_ERR_SPEECH_UNAVAILABLE
        }
        // A stuck Rust must not leave the microphone on (plan S9).
        failsafe = Task { [weak self] in
            try? await Task.sleep(for: .milliseconds(Int(maxMs) + 1000))
            await self?.fail(VB_ERR_FAILED)
        }
        return nil
    }

    func finish() async {
        guard !ended else { return }
        ended = true
        failsafe?.cancel()
        capture.stop() // the microphone is off from here (plan S18)
        do {
            let heard = try await transcription.finish()
            Bridge.shared.emitSession(Event(generation: generation, kind: VB_EV_FINAL, value: UInt32(clamping: heard.latencyMs),
                                            text: heard.text, audioMs: heard.audioMs, voicedMs: heard.voicedMs))
        } catch {
            // Never the error's text (spec §6.3).
            Bridge.shared.emitSession(Event(generation: generation, kind: VB_EV_ERROR, code: UInt32(VB_ERR_SPEECH_UNAVAILABLE)))
        }
    }

    func cancel() async {
        guard !ended else { return }
        ended = true
        failsafe?.cancel()
        capture.stop()
        await transcription.cancel()
    }

    private func fail(_ code: Int32) async {
        guard !ended else { return }
        await cancel()
        Bridge.shared.emitSession(Event(generation: generation, kind: VB_EV_ERROR, code: UInt32(code)))
    }
}
#endif
```

```swift
enum Command: Sendable {
    case capabilities
    case start(UInt64, UInt32)
    case stop(UInt64)
    case cancel(UInt64)
    /// Lock or sleep: drop whatever runs (spec §6.2).
    case stopAll
    case installAssets
}

/// The bounded, ordered command queue (plan S4). A full queue drops the
/// command. A dropped stop ends in Rust's final timeout; a dropped cancel
/// ends at the failsafe. Neither routes anything.
final class Commands: @unchecked Sendable {
    static let capacity = 64
    static let shared = Commands(start: true)

    let stream: AsyncStream<Command>
    private let sink: AsyncStream<Command>.Continuation

    init(start: Bool) {
        (stream, sink) = AsyncStream.makeStream(of: Command.self, bufferingPolicy: .bufferingOldest(Commands.capacity))
        if start {
            let stream = self.stream
            Task.detached { await Runner.shared.run(stream) }
        }
    }

    @discardableResult
    func send(_ command: Command) -> Bool {
        if case .dropped = sink.yield(command) { return false }
        return true
    }
}

struct Caps: Sendable {
    /// Whether SpeechTranscriber streams volatile results in the bundle.
    /// From the step-2 spike record (plan S22); true unless it showed none.
    static let partialsStream = true

    var unavailable: UInt32
    var streamsPartials = false
    var sampleRate: UInt32 = 0
    var locale: Locale? = nil

    var event: Event {
        Event(kind: VB_EV_CAPS, code: unavailable, value: streamsPartials ? 1 : 0, value2: sampleRate, text: locale?.identifier)
    }

    static func query() async -> Caps {
        #if compiler(>=6.2)
        guard #available(macOS 26.0, *) else { return Caps(unavailable: VB_UA_OS_TOO_OLD) }
        guard SpeechTranscriber.isAvailable else { return Caps(unavailable: VB_UA_TRANSCRIBER_UNSUPPORTED) }
        guard let locale = await Locales.resolve() else { return Caps(unavailable: VB_UA_LOCALE_UNSUPPORTED) }
        guard await Locales.isInstalled(locale) else { return Caps(unavailable: VB_UA_ASSETS_MISSING, locale: locale) }
        let format = await Transcription(locale: locale).format()
        return Caps(unavailable: VB_UA_NONE, streamsPartials: Caps.partialsStream, sampleRate: UInt32(format?.sampleRate ?? 0), locale: locale)
        #else
        return Caps(unavailable: VB_UA_SDK_TOO_OLD)
        #endif
    }

    /// The system download for the English model (spec §9, plan S21).
    static func install() async -> Int32 {
        #if compiler(>=6.2)
        guard #available(macOS 26.0, *), let locale = await Locales.resolve() else { return VB_ERR_SPEECH_UNAVAILABLE }
        let module = SpeechTranscriber(locale: locale, transcriptionOptions: [], reportingOptions: [], attributeOptions: [])
        do {
            if let request = try await AssetInventory.assetInstallationRequest(supporting: [module]) {
                try await request.downloadAndInstall()
            }
            return VB_OK
        } catch {
            return VB_ERR_FAILED
        }
        #else
        return VB_ERR_SPEECH_UNAVAILABLE
        #endif
    }
}

/// Owns the session and handles commands one at a time, in order. Stop and
/// cancel never wait for a session to finish.
actor Runner {
    static let shared = Runner()
    private var session: (any Session)?
    private var caps = Caps(unavailable: VB_UA_TRANSCRIBER_UNSUPPORTED)

    func run(_ commands: AsyncStream<Command>) async {
        for await command in commands {
            await handle(command)
        }
    }

    private func handle(_ command: Command) async {
        switch command {
        case .capabilities:
            caps = await Caps.query()
            Bridge.shared.setCaps(caps.event)
            Bridge.shared.emit(caps.event)
        case let .start(generation, maxMs):
            drop()
            Bridge.shared.setCurrent(generation)
            guard let s = makeSession(generation) else {
                Bridge.shared.emitSession(Event(generation: generation, kind: VB_EV_ERROR, code: UInt32(VB_ERR_SPEECH_UNAVAILABLE)))
                return
            }
            session = s
            if let code = await s.start(maxMs: maxMs) {
                if session === s { session = nil }
                Bridge.shared.emitSession(Event(generation: generation, kind: VB_EV_ERROR, code: UInt32(code)))
            }
        case let .stop(generation):
            guard let s = session, s.generation == generation else { return }
            // Still current, so its final passes the filter.
            session = nil
            Task { await s.finish() }
        case let .cancel(generation):
            guard let s = session, s.generation == generation else { return }
            drop()
        case .stopAll:
            drop()
        case .installAssets:
            let code = await Caps.install()
            Bridge.shared.emit(Event(kind: VB_EV_ASSETS, code: UInt32(bitPattern: code)))
            await handle(.capabilities)
        }
    }

    /// Cancels the live session; its events are dropped from now on.
    private func drop() {
        guard let s = session else { return }
        session = nil
        Bridge.shared.setCurrent(0)
        Task { await s.cancel() }
    }

    private func makeSession(_ generation: UInt64) -> (any Session)? {
        #if compiler(>=6.2)
        if #available(macOS 26.0, *), let locale = caps.locale, caps.unavailable == VB_UA_NONE {
            return LiveSession(generation: generation, locale: locale)
        }
        #endif
        return nil
    }
}
```

```swift
import CoreGraphics
import Foundation
import VoiceBridgeC

/// The listen-only hold-key tap (spec §4.1, plan S11). It sees every key,
/// so it forwards only the hold key's down and up, and, while the hold key
/// is down, "another key" with no key code. It never changes an event.
final class HoldTap: @unchecked Sendable {
    static let shared = HoldTap()

    private let bridge: Bridge
    private let lock = NSLock()
    private var runLoop: CFRunLoop?
    private var port: CFMachPort?
    // Touched only on the tap thread (or by a test, with no tap running).
    private var keycode: Int64 = 61
    private var mask: UInt64 = 0x40
    private var down = false

    init(bridge: Bridge = .shared) {
        self.bridge = bridge
    }

    func configure(keycode: UInt16, mask: UInt64) {
        self.keycode = Int64(keycode)
        self.mask = mask
        down = false
    }

    /// Starts the tap on its own thread and run loop, so a busy main thread
    /// never delays a key-up.
    func start(keycode: UInt16, mask: UInt64) -> Int32 {
        stop()
        guard Permissions.status(VB_PERM_INPUT_MONITORING) == VB_PS_GRANTED else { return VB_ERR_INPUT_MONITORING_DENIED }
        configure(keycode: keycode, mask: mask)
        let ready = DispatchSemaphore(value: 0)
        var created = false
        let thread = Thread { [self] in
            let events = CGEventMask(1 << CGEventType.flagsChanged.rawValue) | CGEventMask(1 << CGEventType.keyDown.rawValue)
            guard let tap = CGEvent.tapCreate(tap: .cgSessionEventTap, place: .headInsertEventTap, options: .listenOnly,
                                              eventsOfInterest: events, callback: holdTapCallback,
                                              userInfo: Unmanaged.passUnretained(self).toOpaque()) else {
                ready.signal()
                return
            }
            let source = CFMachPortCreateRunLoopSource(nil, tap, 0)
            CFRunLoopAddSource(CFRunLoopGetCurrent(), source, .commonModes)
            CGEvent.tapEnable(tap: tap, enable: true)
            lock.lock()
            port = tap
            runLoop = CFRunLoopGetCurrent()
            lock.unlock()
            created = true
            ready.signal()
            CFRunLoopRun()
            CFMachPortInvalidate(tap)
        }
        thread.name = "dev.agentcaller.voice.tap"
        thread.start()
        // Tap creation takes milliseconds; never wait long.
        _ = ready.wait(timeout: .now() + 1)
        return created ? VB_OK : VB_ERR_TAP_FAILED
    }

    func stop() {
        lock.lock()
        let loop = runLoop
        let tap = port
        runLoop = nil
        port = nil
        lock.unlock()
        if let tap { CGEvent.tapEnable(tap: tap, enable: false) }
        if let loop { CFRunLoopStop(loop) }
    }

    func handle(_ type: CGEventType, _ event: CGEvent) {
        switch type {
        case .tapDisabledByTimeout, .tapDisabledByUserInput:
            lock.lock()
            let tap = port
            lock.unlock()
            var back = false
            if let tap {
                CGEvent.tapEnable(tap: tap, enable: true)
                back = CGEvent.tapIsEnabled(tap: tap)
            }
            // A key-up may have been lost; Rust cancels a held recording.
            down = false
            bridge.emit(Event(kind: VB_EV_TAP_DISABLED, code: type == .tapDisabledByTimeout ? 1 : 2, value: back ? 1 : 0))
        case .flagsChanged:
            if event.getIntegerValueField(.keyboardEventKeycode) == keycode {
                let now = event.flags.rawValue & mask != 0
                if now != down {
                    down = now
                    bridge.emit(Event(kind: VB_EV_HOLD, value: now ? 1 : 0))
                }
            } else if down {
                bridge.emit(Event(kind: VB_EV_OTHER_KEY))
            }
        case .keyDown:
            if down { bridge.emit(Event(kind: VB_EV_OTHER_KEY)) }
        default:
            break
        }
    }
}

private func holdTapCallback(proxy: CGEventTapProxy, type: CGEventType, event: CGEvent, info: UnsafeMutableRawPointer?) -> Unmanaged<CGEvent>? {
    if let info {
        Unmanaged<HoldTap>.fromOpaque(info).takeUnretainedValue().handle(type, event)
    }
    return Unmanaged.passUnretained(event)
}

@_cdecl("vb_tap_start")
public func vb_tap_start(_ keycode: UInt16, _ mask: UInt64) -> Int32 {
    HoldTap.shared.start(keycode: keycode, mask: mask)
}

@_cdecl("vb_tap_stop")
public func vb_tap_stop() {
    HoldTap.shared.stop()
}
```

```rust
/// Registers the voice toggle, or unregisters it with `None`.
pub fn apply_voice(app: &AppHandle, hotkey: Option<&str>) -> Result<(), String> {
    let next = hotkey.map(|h| check_voice(h, current_shortcut())).transpose()?;
    let shortcuts = app.global_shortcut();
    let mut voice = VOICE_SHORTCUT.lock().map_err(|_| "Voice shortcut lock poisoned".to_string())?;
    if *voice == next {
        return Ok(());
    }
    if let Some(shortcut) = next {
        shortcuts
            .register(shortcut)
            .map_err(|error| format!("Could not register {shortcut}: {error}"))?;

        && let Err(error) = shortcuts.unregister(old)
    {
        tracing::warn!(%error, "could not unregister the previous voice shortcut");
    }
    Ok(())
}
```

```rust
//! The voice triggers (spec §4.1, §6.2): the listen-only hold-key tap and
//! the toggle shortcut. Both run only while voice is on (plan S12).
use std::sync::atomic::{AtomicBool, Ordering};

use tauri::{AppHandle, Manager};

use super::VoiceState;
use super::permissions::{self, Permission, PermissionState, TAP_NEEDS_RELAUNCH};
use super::settings::{HoldKey, VoiceSettings};

static HOLD_ACTIVE: AtomicBool = AtomicBool::new(false);

/// macOS virtual key code, and the flag bit that is set while that key is down.
pub fn mac_key(key: HoldKey) -> Option<(u16, u64)> {
    match key {
        HoldKey::RightOption => Some((61, 0x0000_0040)),  // NX_DEVICERALTKEYMASK
        HoldKey::LeftOption => Some((58, 0x0000_0020)),   // NX_DEVICELALTKEYMASK
        HoldKey::RightCommand => Some((54, 0x0000_0010)), // NX_DEVICERCMDKEYMASK
        HoldKey::RightControl => Some((62, 0x0000_2000)), // NX_DEVICERCTLKEYMASK
        HoldKey::Fn => Some((63, 0x0080_0000)),           // NX_SECONDARYFNMASK
        HoldKey::Off => None,
    }
}

#[derive(Debug, PartialEq, Eq)]
pub enum TapError {
    InputMonitoringDenied,
    Failed,
}

pub fn tap_result(code: i32) -> Result<(), TapError> {
    match code {
        super::bridge::VB_OK => Ok(()),
        super::bridge::VB_ERR_INPUT_MONITORING_DENIED => Err(TapError::InputMonitoringDenied),
        _ => Err(TapError::Failed),
    }
}

pub fn should_start_hold(enabled: bool, key: HoldKey, granted: bool, active: bool) -> bool {
    enabled && key != HoldKey::Off && granted && !active
}

pub fn hold_active() -> bool {
    HOLD_ACTIVE.load(Ordering::SeqCst)
}

/// The system disabled the tap and it did not come back.
pub fn hold_off() {
    HOLD_ACTIVE.store(false, Ordering::SeqCst);
}

fn start_hold(key: HoldKey) {
    let Some((code, mask)) = mac_key(key) else {
        return;
    };
    // SAFETY: plain integers; returns within a second (Tap.swift).
    let result = tap_result(unsafe { super::bridge::ffi::vb_tap_start(code, mask) });
    if let Err(error) = &result {
        tracing::info!(?error, "the hold key is off");
    }
    HOLD_ACTIVE.store(result.is_ok(), Ordering::SeqCst);
}

fn stop_hold() {
    // SAFETY: no arguments.
    unsafe { super::bridge::ffi::vb_tap_stop() }
    HOLD_ACTIVE.store(false, Ordering::SeqCst);
}

/// Makes both triggers match `settings`. Returns the toggle shortcut's
/// registration error, for Settings.
pub fn apply(app: &AppHandle, settings: &VoiceSettings) -> Option<String> {
    stop_hold();
    let toggle = settings.toggle_shortcut.as_deref().filter(|_| settings.enabled);
    let error = crate::hotkey::apply_voice(app, toggle).err();
    let granted = permissions::status(Permission::InputMonitoring) == PermissionState::Granted;
    if should_start_hold(settings.enabled, settings.hold_key, granted, false) {
        start_hold(settings.hold_key);
    }
    error
}

/// Starts the hold key if it should run and does not, for example right
/// after Input Monitoring was granted (plan S17).
pub fn refresh(app: &AppHandle) {
    if TAP_NEEDS_RELAUNCH {
        return;
    }
    let voice = app.state::<VoiceState>();
    let settings = voice.settings.lock().unwrap().clone();
    let granted = permissions::status(Permission::InputMonitoring) == PermissionState::Granted;
    if should_start_hold(settings.enabled, settings.hold_key, granted, hold_active()) {
        start_hold(settings.hold_key);
    }
}

/// The toggle shortcut fired.
pub fn toggle(app: &AppHandle) {
    let voice = app.state::<VoiceState>();
    voice.controller.toggle(crate::panel::is_visible());
}
```

```rust
pub fn summary_icon(color: TrayColor, listening: bool) -> Vec<u8> {
    let c = rgba(color);
    let (mid, r) = (SIZE as f32 / 2.0, SIZE as f32 * 0.32);
    let (mic_x, mic_y, mic_r) = (SIZE as f32 * 0.82, SIZE as f32 * 0.18, SIZE as f32 * 0.16);
    let mut out = Vec::with_capacity((SIZE * SIZE * 4) as usize);
    for y in 0..SIZE {
        for x in 0..SIZE {
            let (px, py) = (x as f32 + 0.5, y as f32 + 0.5);
            let (dx, dy) = (px - mid, py - mid);
            let (mx, my) = (px - mic_x, py - mic_y);
            if listening && mx * mx + my * my <= mic_r * mic_r {
                out.extend_from_slice(&MIC);
            } else if dx * dx + dy * dy <= r * r {
                out.extend_from_slice(&c);
            } else {
                out.extend_from_slice(&[0, 0, 0, 0]);
            }
        }
    }
    out
}
```

```rust
//! What Settings shows about voice (spec §6.4, §8, §9). No voice content.
use acd_voice::listen::{Capabilities, Unavailable};
use serde::Serialize;

use super::permissions::{Permission, PermissionState, SPEECH_PERMISSION_REQUIRED, TAP_NEEDS_RELAUNCH};

#[derive(Clone, Debug, PartialEq, Eq, Serialize)]
pub struct VoiceStatus {
    pub unavailable: Option<Unavailable>,
    pub streams_partials: bool,
    pub locale: Option<String>,
    pub microphone: PermissionState,
    /// `None` when Speech Recognition is not needed (plan S14).
    pub speech: Option<PermissionState>,
    pub input_monitoring: PermissionState,
    pub hold_key_active: bool,
    /// Input Monitoring is granted but the tap waits for a relaunch (S17).
    pub relaunch_for_hold_key: bool,
    /// Why the voice shortcut could not be registered.
    pub toggle_error: Option<String>,
}

pub fn build(
    caps: Capabilities,
    locale: Option<String>,
    perm: impl Fn(Permission) -> PermissionState,
    hold_key_active: bool,
    hold_key_wanted: bool,
    toggle_error: Option<String>,
) -> VoiceStatus {
    let input_monitoring = perm(Permission::InputMonitoring);
    VoiceStatus {
        unavailable: caps.unavailable,
        streams_partials: caps.streams_partials,
        locale,
        microphone: perm(Permission::Microphone),
        speech: SPEECH_PERMISSION_REQUIRED.then(|| perm(Permission::Speech)),
        input_monitoring,
        hold_key_active,
        relaunch_for_hold_key: TAP_NEEDS_RELAUNCH
            && hold_key_wanted
            && !hold_key_active
            && input_monitoring == PermissionState::Granted,
        toggle_error,
    }
}

#[cfg(target_os = "macos")]
pub fn current(app: &tauri::AppHandle) -> VoiceStatus {
    use acd_voice::listen::SpeechInput;
    use tauri::Manager;

    use super::settings::HoldKey;

    let voice = app.state::<super::VoiceState>();
    let settings = voice.settings.lock().unwrap().clone();
    build(
        voice.speech.capabilities(),
        voice.speech.locale(),
        super::permissions::status,
        super::trigger::hold_active(),
        settings.enabled && settings.hold_key != HoldKey::Off,
        voice.trigger_error.lock().unwrap().clone(),
    )
}
```
