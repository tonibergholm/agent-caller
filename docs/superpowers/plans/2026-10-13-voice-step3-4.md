# Voice steps 3 and 4 implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give free-form voice commands an on-device intent model (Apple Foundation Models, voice spec §11 item 3), then speak templated replies and optional alerts aloud (spec §11 item 4), on macOS only.

**Architecture:** The router, its validation and the safety table do not change. They stay authoritative over whatever the model returns. Swift gains two parts behind the existing C ABI: `ModelRequests`, which runs one fresh `LanguageModelSession` per plan with guided generation, and `Speaker`, which wraps `AVSpeechSynthesizer`. Each has its own id counter and event kinds. Rust gets `MacIntentModel: IntentModel`, which adds a timeout and cancels on drop, and `MacSpeaker: Speaker`. The `Speaker` trait and the alert rules live in `acd-voice` as plain Rust with time passed in, like `listen.rs`. The controller decides when to speak and when to stop.

**Tech Stack:** Rust 2024 (workspace `rust-version = "1.90"`), tokio, async-trait; Swift 6.4 toolchain in Swift 5 language mode, SwiftPM, XCTest; FoundationModels (`SystemLanguageModel`, `LanguageModelSession`, `@Generable`, `@Guide`; macOS 26 SDK, Xcode 27), AVFoundation `AVSpeechSynthesizer`; Tauri 2.12.1; Svelte 5, vitest.

**Spec:** `docs/superpowers/specs/2026-10-11-voice-design.md` (authoritative), mainly §3, §4.1, §4.2, §4.4, §5.4, §5.5, §6.2, §6.3, §7, §8, §9, §10, §11, §12. Step-1 decisions D1 to D25 and step-2 decisions S1 to S27 still hold (`docs/superpowers/plans/2026-10-11-voice-step1.md`, `docs/superpowers/plans/2026-10-12-voice-step2.md`). This plan's decisions use the prefix V so they never collide with those.

## Decisions made in this plan

- **V1. One fresh `LanguageModelSession` per plan.** A reused session keeps its transcript: agent text from an earlier utterance would sit in the next prompt, the on-device context (about 4K tokens) would fill up, and a cancelled request still running would make the next call fail with `concurrentRequests`. `prewarm` creates at most one unused session, which the next plan takes; a plan never reuses a session after it ran. "Model sessions are discarded" (§6.3) therefore means: cancel in-flight requests and drop the prewarmed session.
- **V2. Instructions and untrusted data cross separately.** `Prompt::render_input()` returns the DATA and TRANSCRIPT sections without the instructions. Swift passes `INSTRUCTIONS` (sent from Rust, one source of truth) as the session's `instructions:` and the input as the prompt. Apple's guidance puts untrusted content in the prompt, never in instructions. Swift copies both strings before `vb_model_plan` returns.
- **V3 (amended by Task 5b, 2026-10-13).** The measured result of the flat struct below was 5 of 20 phrases (docs/research/2026-10-13-voice-model-contract.md): the model filled every optional field, and Rust refused the contradictory plans. The guided type is now `GuidedPlan { want, step: GuidedStep }`, an enum with one case per step carrying only that step's fields, and a one-sentence `want` the model writes first (never sent to Rust). It has no `candidates`: the wire format and `ModelPlan` keep the field for models that offer it, Rust's `INSTRUCTIONS` no longer mention it, and a test pins that. `tests/fixtures/voice/plan-cases.json` pins the nine plans the cases can write on both sides. Results: docs/research/2026-10-13-voice-model-quality.md. The original V3 text follows for the record.
- **V3 (original). The guided type mirrors `ModelPlan` exactly, and fixtures pin it on both sides.** `GuidedPlan` has the seven properties `step agent request option text machine candidates`. `step` is a `String` guided by `.anyOf` of the eight snake_case step names, not a Swift enum, because the enum's encoding cannot be confirmed. Swift turns it into wire JSON with its own `PlanJSON` encoder (sorted keys, absent fields omitted). `tests/fixtures/voice/plan-full.json`, `plan-min.json` and `plan-steps.json` are checked by an XCTest and by a Rust test against `plan_schema()` and `ModelPlan`. None of this needs Apple Intelligence.
- **V4. Model requests and speech have their own ids and event kinds.** `Bridge.isStale` drops `VB_EV_PARTIAL`, `VB_EV_FINAL` and `VB_EV_ERROR` whenever no recording is live, so model replies use new kinds (`VB_EV_MODEL`, `VB_EV_MODEL_CAPS`, later `VB_EV_SPOKEN`, `VB_EV_VOICES`). `MacIntentModel` and the controller keep their own counters. Replies share the bounded outbox (S5); an overflow invalidates voice, which drops every waiting plan.
- **V5. The timeout is enforced in Rust; Swift has a backstop.** `MacIntentModel::plan` waits with `tokio::time::timeout(MODEL_TIMEOUT)`. A guard calls `vb_model_cancel(id)` whenever the future ends without a reply: timeout, cancellation, or a dropped route. Swift gives up on its own at the timeout plus 1 s. `MODEL_TIMEOUT` was 5 s, the spec's cloud figure, pending the owner (decision 1) and Task 5's latency numbers. Task 5b measured a slowest cold call of 4.0 s with the restatement step; the rule gives 5.0 s and the constant is 6 s, a margin of a second.
- **V6. Availability is read on every request.** On macOS the app always passes `Some(MacIntentModel)`. Swift reads `SystemLanguageModel.default.availability` (a synchronous property) at the start of every plan, on prewarm and on `vb_model_query`, and replies `VB_ERR_MODEL_UNAVAILABLE` with the reason at once when it is not available. Swift reports a `VB_EV_MODEL_CAPS` only when the value changed, so Settings can ask on every refresh without a loop. The controller needs no change for runtime toggles: a model that becomes unavailable refuses the next phrase, and one that becomes available works on the next phrase. Rust never gates on a cached state.
- **V7. The HUD names the reason.** `ModelError::Unavailable` carries a `ModelUnavailable` reason. `Refusal` gains `ModelOff` (Apple Intelligence is off) and `ModelNotReady`; other reasons stay `ModelUnavailable`. Settings shows every reason.
- **V8. The on-device model gets request details.** `IntentModel::receives_details()` defaults to false; `MacIntentModel` returns true. `Controller::start` sets `PromptOptions::include_details` from it (spec §5.4). Today the controller hardcodes `RouteOptions::default()`.
- **V9. Cancelling a thinking step cancels the model call.** Today only a session bump drops the route future; `cancel_thinking`, the HUD's Cancel and a press change executor state and leave the Swift request running. The controller publishes `Executor::routing()` (the utterance still thinking) on a watch channel from `emit`; the utterance task's `select!` returns when it changes, which drops the route future and fires V5's guard.
- **V10. `Speaker` lives in `acd-voice` next to `SpeechInput`.** `say(generation, text, voice, rate)` and `stop()` return at once and never call back under the controller's lock. `Controller::spoken(generation)` reports the end; an end for any other generation is ignored. `stop` is synchronous in Swift (`stopSpeaking(at: .immediate)` before it returns), like S4's safety commands.
- **V11. The HUD fades from the end of speech.** `Hud::Speaking` gains `audio: bool`. With `audio: false` (no speaker attached) the D18 timer stays. With `audio: true` the state does not fade on a timer; `HudSink::speech_ended(seq)` schedules the 1.5 s fade (spec §4.4). A cap (`speak::speech_cap`, 1.5 s plus 100 ms per character, 10 s to 120 s) stops speech and hides the HUD if no end arrives.
- **V12. Where speech stops.** A press, before `input.start` (in Rust; Swift's `Sessions.start` also silences first). A new typed or spoken utterance at admission. Voice off, lock, sleep and overflow (`invalidate`; Swift's lock and sleep observers stop speech themselves too). The HUD's Stop button and Esc on the HUD (`voice_stop_speech(seq)`, HUD window only). Esc in the inbox panel, which now stops speech and also runs the existing chain, so one Esc never has to choose between stopping speech and cancelling an inbox countdown. Behaviour change to note in the PR and the release notes: while the app speaks and an inbox countdown runs, one Esc in the inbox panel both stops the speech and undoes the newest inbox countdown (the chain's `core::escape`), exactly as Esc did before speech existed. As in S25, Esc reaches the app only while the inbox panel is open or the HUD was clicked.
- **V13. A spoken reply plays only while its Speaking state is on the HUD.** Any other HUD state replacing it stops speech. Alerts have no HUD state; only V12's stop points end them.
- **V14. Alerts are a pure state machine (`speak::Alerts`).** The first observation after alerts or voice turn on takes a baseline and announces nothing. Seen requests are remembered by (card key, request id), up to 1024, so a reconnect snapshot announces nothing. Eligible cards: in the Request group, online, not a hidden subagent, not a hidden idle agent, and on the filtered machine when a machine filter is set (pending owner decision 2). These rules are applied to the card fields directly, never through `Snapshot::visibility`, which treats a card missing from `presentation.visible` as never visible: a request that just arrived is not in that list until the panel republishes, and the list is empty before the first publish. At most one alert per 5 s: requests that arrive inside the gap are spoken together when it ends, the first named and the rest counted ("minos Claude needs you: bash approval. 2 more need you.", owner decision 3). Queued requests that no longer need the user are dropped before speaking. Alerts wait (1 s retries) while a recording, a step, or other speech is active, and speak only while voice and alerts are both on.
- **V15. Settings.** `voice.json` gains `alerts` (default false), `speech_voice` (an `AVSpeechSynthesisVoice` identifier, `null` means the system's English voice) and `speech_rate` (`slow`, `normal`, `fast`; default `normal`). `VoiceSettings` derives `Eq`, so the rate is an enum, not a float. Swift maps the rates to 0.42, `AVSpeechUtteranceDefaultSpeechRate` (0.5) and 0.58 (owner decision 5).
- **V16. Swift reports voices and model availability only when they change, unless Rust forces a report.** `voice_status` asks for both on every Settings refresh without forcing; the answer re-emits the status only on a change, so there is no refresh loop (the loop that kept `MacSpeech::refresh` unused). After a bridge overflow Rust asks again with `force`, because the dropped events may include the last report; otherwise Settings could stay on "Checking" or an empty voice list for good.
- **V17. `AVSpeechSynthesizer` runs on a private serial queue, never through `DispatchQueue.main.sync`.** The controller calls `say` and `stop` under its core lock, and synchronous Tauri commands on the main thread also take that lock; a `main.sync` could deadlock. Listing voices runs on a second queue, so a slow `speechVoices()` never delays `say` or `stop`. Task 9's live tests confirm speech works off the main thread, and that `say` and `stop` finish while the main thread is blocked.
- **V18. The model contract check runs end to end from Rust.** An ignored test in the app crate starts the real bridge, routes about 20 phrases through `acd_voice::router::route` with `MacIntentModel` against a fixed snapshot, and checks both schema validity and the routed outcome. It prints phrase numbers, tags and timings, never model output.
- **V19. A capture start waits briefly for the audio tail.** `stopSpeaking(at: .immediate)` can return before the last buffer has played. Swift's `Sessions.start` calls `Speaker.silenceForCapture()`, which stops and then waits until the synthesizer reports it is quiet, at most 150 ms (`Speaker.drainMs`), before the microphone opens. Task 12 item 7 checks by ear and by transcript that the tail is not heard.

## Spec issues found

The spec is not edited. Each item is reported here.

1. **§4.1 lists the Speaker interface as `say(text)`, `stop`.** It needs a generation id (§4.2), the voice and rate (§8), and an end report (§4.4 fade). V10.
2. **§9 asks for "Model unavailable" with the reason, but `Refusal` carries no data.** V7 adds two unit variants.
3. **§7 says alerts "speak titles truncated to 60 characters", but the alert template (§7's own example) has no agent title.** The machine name is cut to 60 characters (`speech::alert`, unchanged); the request label is at most 40 characters plus "approval".
4. **§5.4 sends request details to local models, but the controller passes `RouteOptions::default()`** (details off). V8.
5. **§4.4 "fades 1.5 s after ... speech ends" conflicts with D18's character-count timer** once audio exists. V11.
6. **§10 asks for model contract tests against Foundation Models and Anthropic.** Anthropic is out of scope.
7. **§2.1 lists an optional cloud model in the first slice.** Out of scope by user decision; `IntentModel::receives_details` leaves room for its setting.
8. **§7 says "a click" stops speech, but the Speaking state has no input id and `voice_cancel` ignores calls without one.** V12 adds `voice_stop_speech(seq)` and a Stop button.

9. **§5.4 lets the model return `candidates` when unsure; the on-device guided type does not offer it** (Task 5b). Rust still asks which one when the transcript is ambiguous, and every model-produced mutation is still confirmed.

    /// and TRANSCRIPT as its prompt.
    #[test]
    fn the_input_is_the_render_without_the_instructions() {
        let (p, _) = build(&snapshot(vec![pending("m", "a")]), &VoiceText::new("approve"), PromptOptions::default());

/// One plan on the wire (voice spec §5.4, plan V3): Rust's `ModelPlan`, the
/// same seven fields, absent ones omitted, keys sorted.
struct PlanJSON: Encodable, Equatable {
    static let steps = ["answer", "answer_text", "send", "cancel", "read", "summarize", "select", "none"]
    var step: String
    var agent: String? = nil
    var request: String? = nil
    var option: String? = nil
    var text: String? = nil
    var machine: String? = nil
    var candidates: [String]? = nil

    func encoded() -> String {
        let encoder = JSONEncoder()
        encoder.outputFormatting = [.sortedKeys, .withoutEscapingSlashes]
        // Strings and string arrays always encode; the fallback is unreachable.
        let data = (try? encoder.encode(self)) ?? Data("{\"step\":\"none\"}".utf8)
        return String(decoding: data, as: UTF8.self)
    }
}

/// Why a plan failed, classified (spec §6.3). Never an error's text.
enum PlanFailure: Error, Equatable {
    case unavailable(UInt32)
    case timedOut
    case failed
}

/// The model behind the requests; a protocol so tests run without Apple
/// Intelligence.
protocol PlanEngine: AnyObject, Sendable {
    /// VB_MA_*. Cheap; read on every request (plan V6).
    func availability() -> UInt32
    func prewarm(instructions: String)
    /// One plan as wire JSON, from a model session no other plan used (V1).
    func plan(instructions: String, input: String) async throws -> String
    /// Drops the prewarmed session.
    func discard()
}

/// Plans in flight, by the caller's id (plan V4, V5). `lock` guards every
/// var below it. A request leaves `live` when it replies or is cancelled,
/// whichever comes first; only the first may emit.
final class ModelRequests: @unchecked Sendable {
    static let shared = ModelRequests(engine: ModelRequests.live(), bridge: .shared)

    private let engine: PlanEngine
    private let bridge: Bridge
    private let lock = NSLock()
    private var live: Set<UInt64> = []
    private var tasks: [UInt64: Task<Void, Never>] = [:]
    private var reported: UInt32?
    /// Engine calls still running, cancelled or not (review item 11b).
    private var running = 0
    static let maxRunning = 2

    init(engine: PlanEngine, bridge: Bridge) {
        self.engine = engine
        self.bridge = bridge
    }

    var countForTest: Int { lock.withLock { live.count } }
    var runningForTest: Int { lock.withLock { running } }

    private func claimSlot() -> Bool {
        lock.withLock {
            guard running < ModelRequests.maxRunning else { return false }
            running += 1
            return true
        }
    }

    private func releaseSlot() {
        lock.withLock { running -= 1 }
    }

    func start(_ id: UInt64, instructions: String, input: String, timeoutMs: UInt32) -> Int32 {
        guard id != 0 else { return VB_ERR_FAILED }
        lock.withLock { _ = live.insert(id) }
        let task = Task.detached { [self] in
            await run(id, instructions: instructions, input: input, timeoutMs: timeoutMs)
        }
        let gone = lock.withLock { () -> Bool in
            guard live.contains(id) else { return true }
            tasks[id] = task
            return false
        }
        if gone { task.cancel() }
        return VB_OK
    }

    func cancel(_ id: UInt64) {
        let task = lock.withLock { () -> Task<Void, Never>? in
            live.remove(id)
            return tasks.removeValue(forKey: id)
        }
        task?.cancel()
    }

    /// Voice off, lock, sleep, quit (spec §6.3).
    func cancelAll() {
        let all = lock.withLock { () -> [Task<Void, Never>] in
            live.removeAll()
            defer { tasks.removeAll() }
            return Array(tasks.values)
        }
        all.forEach { $0.cancel() }
        engine.discard()
    }

    func prewarm(instructions: String) {
        let code = engine.availability()
        report(code)
        if code == VB_MA_AVAILABLE { engine.prewarm(instructions: instructions) }
    }

    func query(force: Bool = false) {
        report(engine.availability(), force: force)
    }

    private func run(_ id: UInt64, instructions: String, input: String, timeoutMs: UInt32) async {
        var event = Event(generation: id, kind: VB_EV_MODEL)
        let code = engine.availability()
        report(code)
        if code != VB_MA_AVAILABLE {
            event.code = UInt32(VB_ERR_MODEL_UNAVAILABLE)
            event.value = code
        } else if !claimSlot() {
            // Earlier work that ignored its cancellation still runs: refuse
            // now rather than queue behind it (review item 11b).
            event.code = UInt32(VB_ERR_MODEL_FAILED)
        } else {
            defer { releaseSlot() } // runs on every exit, including the cancellation return
            do {
                let engine = self.engine
                event.text = try await ModelRequests.within(ms: UInt64(timeoutMs) + 1000) {
                    try await engine.plan(instructions: instructions, input: input)
                }
                event.code = UInt32(VB_OK)
            } catch is CancellationError {
                return
            } catch PlanFailure.unavailable(let why) {
                report(why)
                event.code = UInt32(VB_ERR_MODEL_UNAVAILABLE)
                event.value = why
            } catch PlanFailure.timedOut {
                event.code = UInt32(VB_ERR_MODEL_TIMEOUT)
            } catch {
                event.code = UInt32(VB_ERR_MODEL_FAILED) // never the error's text
            }
        }
        let current = lock.withLock { () -> Bool in
            tasks.removeValue(forKey: id)
            return live.remove(id) != nil
        }
        if current { bridge.emit(event) }
    }

    /// Emits VB_EV_MODEL_CAPS when the availability changed (plan V16), or
    /// always with `force`: after an overflow Rust cannot know whether the
    /// last report arrived, so it asks again with force (review item 6).
    private func report(_ code: UInt32, force: Bool = false) {
        let send = lock.withLock { () -> Bool in
            guard force || reported != code else { return false }
            reported = code
            return true
        }
        if send { bridge.emit(Event(kind: VB_EV_MODEL_CAPS, code: code)) }
    }

    static func within(ms: UInt64, _ work: @escaping @Sendable () async throws -> String) async throws -> String {
        try await withThrowingTaskGroup(of: String.self) { group in
            group.addTask { try await work() }
            group.addTask {
                try await Task.sleep(nanoseconds: ms * 1_000_000)
                throw PlanFailure.timedOut
            }
            defer { group.cancelAll() }
            guard let first = try await group.next() else { throw PlanFailure.failed }
            return first
        }
    }

    static func live() -> PlanEngine {
        #if canImport(FoundationModels)
        if #available(macOS 26.0, *) { return FoundationPlanEngine() }
        return UnavailableEngine(code: VB_MA_OS_TOO_OLD)
        #else
        return UnavailableEngine(code: VB_MA_SDK_TOO_OLD)
        #endif
    }
}

pub struct MacIntentModel {
    port: Arc<dyn ModelPort>,
    next: AtomicU64,
    waiting: Mutex<HashMap<u64, oneshot::Sender<Reply>>>,
    state: Mutex<ModelState>,
    timeout: Duration,
}

impl MacIntentModel {
    pub fn new(port: Arc<dyn ModelPort>, timeout: Duration) -> Self {
        Self { port, next: AtomicU64::new(0), waiting: Mutex::new(HashMap::new()), state: Mutex::new(ModelState::Checking), timeout }
    }

    /// For Settings. Never used to refuse a plan: Swift checks every time (V6).
    pub fn state(&self) -> ModelState {
        *self.state.lock().unwrap()
    }

    pub fn set_state(&self, state: ModelState) {
        *self.state.lock().unwrap() = state;
    }

    /// Asks Swift for availability; a change arrives as `ModelCaps`.
    pub fn query(&self) {
        self.port.query(false);
    }

    /// The bridge dropped events: the last `ModelCaps` may be among them,
    /// so ask for a report even if nothing changed (review item 6).
    pub fn overflowed(&self) {
        self.port.query(true);
    }

    /// A reply from Swift. False if nothing waits for `id` any more
    /// (cancelled, timed out or discarded): the reply is dropped.
    pub fn deliver(&self, id: u64, reply: Reply) -> bool {
        match self.waiting.lock().unwrap().remove(&id) {
            Some(tx) => tx.send(reply).is_ok(),
            None => false,
        }
    }
}

/// Cancels the Swift request unless it replied (plan V5).
struct Pending<'a> {
    model: &'a MacIntentModel,
    id: u64,
    answered: bool,
}

impl Drop for Pending<'_> {
    fn drop(&mut self) {
        self.model.waiting.lock().unwrap().remove(&self.id);
        if !self.answered {
            self.model.port.cancel(self.id);
        }
    }
}

fn outcome(reply: &Reply) -> &'static str {
    match reply {
        Ok(_) => "ok",
        Err(ModelError::Unavailable(_)) => "unavailable",
        Err(ModelError::Timeout) => "timeout",
        Err(ModelError::Failed) => "failed",
    }
}

#[async_trait]
impl IntentModel for MacIntentModel {
    async fn plan(&self, prompt: &Prompt) -> Reply {
        let id = self.next.fetch_add(1, Ordering::SeqCst) + 1;
        let (tx, rx) = oneshot::channel();
        self.waiting.lock().unwrap().insert(id, tx);
        let mut pending = Pending { model: self, id, answered: false };
        let started = Instant::now();
        let input = prompt.render_input();
        let timeout_ms = u32::try_from(self.timeout.as_millis()).unwrap_or(u32::MAX);
        let code = self.port.plan(id, INSTRUCTIONS, input.expose(), timeout_ms);
        let reply = if code != VB_OK {
            pending.answered = true; // nothing started in Swift
            Err(if code == VB_ERR_NOT_INITIALIZED { ModelError::Unavailable(ModelUnavailable::Unknown) } else { ModelError::Failed })
        } else {
            match tokio::time::timeout(self.timeout, rx).await {
                Ok(Ok(reply)) => {
                    pending.answered = true;
                    reply
                }
                // Discarded (voice off, lock, overflow): Swift was told already.
                Ok(Err(_)) => {
                    pending.answered = true;
                    Err(ModelError::Failed)
                }
                Err(_) => Err(ModelError::Timeout),
            }
        };
        drop(pending);
        tracing::info!(
            target: "acd_voice",
            outcome = outcome(&reply),
            reply_chars = reply.as_ref().map(|t| t.char_len()).unwrap_or(0),
            elapsed_ms = started.elapsed().as_millis() as u64,
            "model plan"
        );
        reply
    }

    fn receives_details(&self) -> bool {
        true
    }

    fn prewarm(&self) {
        self.port.prewarm(INSTRUCTIONS);
    }

    fn discard(&self) {
        self.waiting.lock().unwrap().clear();
        self.port.cancel_all();
    }
}

pub fn alert_cards(s: &Snapshot) -> Vec<&CardSnap> {
    s.cards

        .filter(|c| {
            c.group == Group::Request
                && c.online
                && c.pending.is_some()

pub enum Due {
    Speak(VoiceText),
    /// Look again after this long.
    Wait(Duration),
    Nothing,

/// Which requests were announced, and when (plan V14).
#[derive(Debug, Default)]
pub struct Alerts {
    /// `None` until the baseline is taken.
    seen: Option<HashSet<(String, String)>>,
    queue: Vec<(String, String)>,
    last: Option<Instant>,
}

impl Alerts {
    /// Alerts or voice turned off: the next look takes a new baseline.
    pub fn reset(&mut self) {
        *self = Self::default();
    }

    /// Queues requests not seen before. The first call only takes a baseline.
    pub fn observe(&mut self, s: &Snapshot) {
        let now = keys(s);
        let Some(seen) = &mut self.seen else {
            self.seen = Some(now.into_iter().collect());
            return;
        };
        for key in now.iter() {
            if seen.insert(key.clone()) {
                self.queue.push(key.clone());
            }
        }
        if seen.len() > SEEN_MAX {
            seen.retain(|k| now.contains(k));
        }
    }

    /// What to say now. Queued requests that no longer need the user are
    /// dropped first. `busy`: recording, a step on the HUD, or speech.
    pub fn due(&mut self, s: &Snapshot, now: Instant, busy: bool) -> Due {
        let live = keys(s);
        self.queue.retain(|k| live.contains(k));
        if self.queue.is_empty() {
            return Due::Nothing;
        }
        if busy {
            return Due::Wait(ALERT_RETRY);
        }
        if let Some(last) = self.last
            && now < last + ALERT_GAP
        {
            return Due::Wait(last + ALERT_GAP - now);
        }
        let queued: Vec<(String, String)> = self.queue.drain(..).collect();
        let cards: Vec<&CardSnap> = queued.iter().filter_map(|(card, _)| s.card(card)).collect();
        self.last = Some(now);
        speech::alerts(&cards).map_or(Due::Nothing, Due::Speak)
    }

    #[cfg(test)]
    fn seen_len(&self) -> usize {
        self.seen.as_ref().map_or(0, HashSet::len)
    }
}

use std::time::Duration;

use acd_voice::hud::Hud;
use acd_voice::plan::Reaction;
use acd_voice::speak::{self, Speaker, SpeechSettings};
use acd_voice::text::VoiceText;

use super::{Controller, Core};

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub(super) struct Speaking {
    pub generation: u64,
    pub seq: Option<u64>,
}

impl Controller {
    /// Attaches the platform's speech output (spec §4.1).
    pub fn attach_speaker(&self, speaker: Arc<dyn Speaker>) {
        *self.speaker.lock().unwrap() = Some(speaker);
    }

    /// Spec §8: alerts, voice and rate.
    pub fn set_speech(&self, settings: SpeechSettings) {
        self.core.lock().unwrap().speech = settings;
    }

    /// Test hook: a shorter cap than `speak::speech_cap`.
    #[doc(hidden)]
    pub fn set_speech_cap_for_test(&self, cap: Duration) {
        self.core.lock().unwrap().speech_cap = Some(cap);
    }

    /// The platform finished speaking `generation`. Any other generation
    /// is stale and ignored (spec §4.2).
    pub fn spoken(&self, generation: u64) {
        let mut core = self.core.lock().unwrap();
        let Some(s) = core.speaking.filter(|s| s.generation == generation) else {
            return;
        };
        core.speaking = None;
        if let Some(seq) = s.seq {
            self.sink.speech_ended(seq);
        }
    }

    /// The HUD's Stop button or Esc on it (`Some(seq)`: the state it
    /// showed), or Esc in the inbox panel (`None`). True if speech stopped.
    pub fn stop_speaking(&self, seq: Option<u64>) -> bool {
        let mut core = self.core.lock().unwrap();
        let Some(s) = core.speaking else {
            return false;
        };
        if seq.is_some() && s.seq != seq {
            return false;
        }
        self.stop_speech(&mut core);
        if s.seq.is_some() {
            self.emit(&mut core, Reaction { hud: Hud::Hidden, select: None });
        }
        true
    }

    pub(super) fn speaker(&self) -> Option<Arc<dyn Speaker>> {
        self.speaker.lock().unwrap().clone()
    }

    /// Says a reply; false without a speaker (the HUD then uses D18's timer).
    pub(super) fn say_reply(&self, core: &mut Core, text: &VoiceText) -> bool {
        let Some(speaker) = self.speaker() else {
            return false;
        };
        let generation = self.start_speech(core, &speaker, text);
        core.speaking = Some(Speaking { generation, seq: None });
        tracing::info!(target: "acd_voice", chars = text.char_len(), "speaking");
        true
    }

    pub(super) fn start_speech(&self, core: &mut Core, speaker: &Arc<dyn Speaker>, text: &VoiceText) -> u64 {
        core.next_speech += 1;
        let generation = core.next_speech;
        speaker.say(generation, text, core.speech.voice.as_deref(), core.speech.rate);
        let cap = core.speech_cap.unwrap_or_else(|| speak::speech_cap(text));
        let me = self.me.clone();
        self.runtime.spawn(async move {
            tokio::time::sleep(cap).await;
            if let Some(this) = me.upgrade() {
                this.cap_reached(generation);
            }
        });
        generation
    }

    /// No end arrived in time (Review Focus 5): stop, and hide a reply.
    fn cap_reached(&self, generation: u64) {
        let mut core = self.core.lock().unwrap();
        let Some(s) = core.speaking.filter(|s| s.generation == generation) else {
            return;
        };
        tracing::info!(target: "acd_voice", "speech cut at its cap");
        self.stop_speech(&mut core);
        if s.seq.is_some() {
            self.emit(&mut core, Reaction { hud: Hud::Hidden, select: None });
        }
    }

    /// Stops what is speaking, if anything.
    pub(super) fn stop_speech(&self, core: &mut Core) {
        if core.speaking.take().is_some()
            && let Some(speaker) = self.speaker()
        {
            speaker.stop();
        }
    }

    /// Stops the speaker whatever Rust believes is speaking: the press path,
    /// where the microphone opens next.
    pub(super) fn silence(&self, core: &mut Core) {
        core.speaking = None;
        if let Some(speaker) = self.speaker() {
            speaker.stop();
        }
    }
}

use std::time::Instant;
use acd_voice::speak::Due;

impl Controller {
    /// Runs `alert_tick` on the runtime, off any lock the caller holds.
    pub(super) fn alert_tick_soon(&self) {
        let me = self.me.clone();
        self.runtime.spawn(async move {
            if let Some(this) = me.upgrade() {
                this.alert_tick();
            }
        });
    }

    /// Looks for requests to announce (plan V14). The snapshot is frozen
    /// before the core lock is taken, as `hold` does.
    pub(super) fn alert_tick(&self) {
        let snapshot = self.freeze(false);
        let mut core = self.core.lock().unwrap();
        let speaker = self.speaker();
        let Some(speaker) = speaker.filter(|_| core.enabled && core.speech.alerts) else {
            core.alerts.reset();
            return;
        };
        core.alerts.observe(&snapshot);
        let busy = core.recorder.active().is_some()
            || core.unadmitted.is_some()
            || !core.exec.is_idle()
            || core.speaking.is_some();
        match core.alerts.due(&snapshot, Instant::now(), busy) {
            Due::Speak(text) => {
                let generation = self.start_speech(&mut core, &speaker, &text);
                core.speaking = Some(Speaking { generation, seq: None });
                tracing::info!(target: "acd_voice", chars = text.char_len(), "alert spoken");
            }
            Due::Wait(after) if !core.alert_timer => {
                core.alert_timer = true;
                let me = self.me.clone();
                self.runtime.spawn(async move {
                    tokio::time::sleep(after).await;
                    if let Some(this) = me.upgrade() {
                        this.core.lock().unwrap().alert_timer = false;
                        this.alert_tick();
                    }
                });
            }
            Due::Wait(_) | Due::Nothing => {}
        }
    }
}

/// Speech synthesis, behind a protocol so tests run without audio.
protocol SynthEngine: AnyObject, Sendable {
    /// `done(true)` when it finished, `done(false)` if stopped or failed;
    /// once, on any thread.
    func speak(_ text: String, voice: String?, rate: Float, done: @escaping @Sendable (Bool) -> Void)
    /// Stops at once. Audio already handed to the output may still play
    /// briefly; `isSpeaking` turns false when it is done.
    func stop()
    var isSpeaking: Bool { get }
    func voices() -> [VoiceInfo]
}

/// AVSpeechSynthesizer. `lock` guards `done`.
final class AVSynth: NSObject, SynthEngine, AVSpeechSynthesizerDelegate, @unchecked Sendable {
    private let synth = AVSpeechSynthesizer()
    private let lock = NSLock()
    private var done: [ObjectIdentifier: @Sendable (Bool) -> Void] = [:]
    /// Live tests only.
    var volume: Float = 1

    override init() {
        super.init()
        synth.delegate = self
    }

    func speak(_ text: String, voice: String?, rate: Float, done: @escaping @Sendable (Bool) -> Void) {
        let utterance = AVSpeechUtterance(string: text)
        utterance.voice = voice.flatMap { AVSpeechSynthesisVoice(identifier: $0) } ?? AVSynth.english()
        utterance.rate = rate
        utterance.volume = volume
        lock.withLock { self.done[ObjectIdentifier(utterance)] = done }
        synth.speak(utterance)
    }

    func stop() {
        synth.stopSpeaking(at: .immediate)
    }

    var isSpeaking: Bool { synth.isSpeaking }

    func voices() -> [VoiceInfo] {
        AVSpeechSynthesisVoice.speechVoices()
            .filter { $0.language.hasPrefix("en") }
            .map { VoiceInfo(id: $0.identifier, name: $0.name, language: $0.language) }
            .sorted { ($0.language, $0.name) < ($1.language, $1.name) }
    }

    /// The templates are English (spec §7): the system language if it is
    /// English, else en-US (owner decision 5).
    static func english() -> AVSpeechSynthesisVoice? {
        let current = AVSpeechSynthesisVoice.currentLanguageCode()
        return AVSpeechSynthesisVoice(language: current.hasPrefix("en") ? current : "en-US")
    }

    func speechSynthesizer(_ synthesizer: AVSpeechSynthesizer, didFinish utterance: AVSpeechUtterance) {
        finish(utterance, true)
    }

    func speechSynthesizer(_ synthesizer: AVSpeechSynthesizer, didCancel utterance: AVSpeechUtterance) {
        finish(utterance, false)
    }

    private func finish(_ utterance: AVSpeechUtterance, _ ok: Bool) {
        let d = lock.withLock { done.removeValue(forKey: ObjectIdentifier(utterance)) }
        d?(ok)
    }
}

/// One voice at a time, by generation (plan V10, V17). Speech runs on
/// `queue`, a private serial queue, never the main thread; `current` is
/// confined to it. Listing voices runs on `voicesQueue`, so a slow
/// `speechVoices()` never delays `say` or `stop`, which Rust calls under its
/// core lock (review item 5); `lastVoices` is confined to `voicesQueue`.
/// Nothing on either queue waits for Rust.
final class Speaker: @unchecked Sendable {
    static let shared = Speaker(engine: AVSynth(), bridge: .shared)
    /// How long a capture start waits for the synthesizer to go quiet.
    static let drainMs = 150

    private let engine: SynthEngine
    private let bridge: Bridge
    private let queue = DispatchQueue(label: "dev.agentcaller.voice.speaker")
    private let voicesQueue = DispatchQueue(label: "dev.agentcaller.voice.voices")
    private var current: UInt64 = 0
    private var lastVoices: [VoiceInfo]?

    init(engine: SynthEngine, bridge: Bridge) {
        self.engine = engine
        self.bridge = bridge
    }

    static func avRate(_ code: UInt32) -> Float {
        switch code {
        case VB_RATE_SLOW: return 0.42
        case VB_RATE_FAST: return 0.58
        default: return AVSpeechUtteranceDefaultSpeechRate
        }
    }

    func say(_ generation: UInt64, text: String, voice: String?, rate: UInt32) {
        queue.sync {
            if current != 0 { engine.stop() }
            current = generation
            engine.speak(text, voice: voice, rate: Speaker.avRate(rate)) { [weak self] finished in
                self?.queue.async { self?.ended(generation, finished) }
            }
        }
    }

    /// Returns after the synthesizer was told to stop.
    func stop() {
        queue.sync {
            current = 0
            engine.stop()
        }
    }

    /// Before a capture opens (review item 11c): stop, then wait at most
    /// `drainMs` for the synthesizer to report it is no longer speaking, so
    /// the transcriber does not hear the tail of the app's own voice.
    /// Bounded, so a synthesizer that never reports quiet cannot hold the
    /// microphone back.
    func silenceForCapture() {
        stop()
        let deadline = Date().addingTimeInterval(Double(Speaker.drainMs) / 1000)
        while engine.isSpeaking && Date() < deadline {
            usleep(5_000)
        }
    }

    /// `force`: report even if unchanged (Rust asks after an overflow).
    func reportVoices(force: Bool = false) {
        voicesQueue.async {
            let voices = self.engine.voices()
            guard force || voices != self.lastVoices else { return }
            self.lastVoices = voices
            let encoder = JSONEncoder()
            encoder.outputFormatting = [.sortedKeys]
            let json = (try? encoder.encode(voices)).map { String(decoding: $0, as: UTF8.self) } ?? "[]"
            self.bridge.emit(Event(kind: VB_EV_VOICES, text: json))
        }
    }

    /// Tests: waits until work queued so far on both queues ran.
    func flushForTest() {
        queue.sync {}
        voicesQueue.sync {}
    }

    private func ended(_ generation: UInt64, _ finished: Bool) {
        guard current == generation else { return }
        current = 0
        bridge.emit(Event(generation: generation, kind: VB_EV_SPOKEN, value: finished ? 1 : 0))
    }
}

@_cdecl("vb_speech_say")
public func vb_speech_say(_ generation: UInt64, _ text: UnsafePointer<UInt8>?, _ textLen: Int,
                          _ voice: UnsafePointer<UInt8>?, _ voiceLen: Int, _ rate: UInt32) {
    guard generation != 0, let t = copyText(text, textLen), let v = copyText(voice, voiceLen) else { return }
    Speaker.shared.say(generation, text: t, voice: v.isEmpty ? nil : v, rate: rate)
}

@_cdecl("vb_speech_stop")
public func vb_speech_stop() {
    Speaker.shared.stop()
}

@_cdecl("vb_speech_voices")
public func vb_speech_voices(_ force: UInt32) {
    Speaker.shared.reportVoices(force: force != 0)
}

/// Hides the HUD `after` from now, unless a newer state replaced `seq`.
pub fn schedule_fade(app: &AppHandle, seq: u64, after: Duration) {
    let handle = app.clone();
    tauri::async_runtime::spawn(async move {
        tokio::time::sleep(after).await;
        let inner = handle.clone();
        // The check runs on the main thread, in order with `present`'s
        // closures, so a newer state cannot be hidden by a late fade.
        if let Err(error) = handle.run_on_main_thread(move || {
            if !fade_applies(LAST_SEQ.load(Ordering::SeqCst), seq) {
                return;
            }
            apply(&inner, true, false);
            if let Err(error) = inner.emit("voice://hud-clear", seq) {
                tracing::error!(%error, "could not emit the HUD fade");
            }
        }) {
            tracing::error!(%error, "could not dispatch the HUD fade");
        }
    });
}

## Decisions the owner must confirm

1. **Model timeout.** Recommendation: 5 s, the figure §9 gives the cloud model, then adjust from Task 5, which reports the cold first call separately from the warm p50 and p95. The timeout must cover the cold call the user meets after an idle period: use the larger of warm p95 plus 1 s and the slower cold call plus 1 s, capped at 8 s. The failure mode of too short is "The model did not answer" on the first phrase after idle; too long leaves the HUD thinking.
2. **Alerts for machines hidden by the machine filter.** Recommendation: do not announce them, as §7 says alerts "respect the ... machine visibility rules". The alternative follows D16 (summaries include filter-hidden cards), which would make an alert the way to hear about another machine while filtered.
3. **Coalescing.** Recommendation: merge into one alert that names the first request and counts the rest ("... 2 more need you."), so no request goes unmentioned. The alternative drops extras inside the 5 s window, which is quieter but loses information.
4. **Alerts for Done or idle agents.** Recommendation: no, only requests that need the user, matching §7's template and the "actionable only" direction for the inbox. Done and idle alerts can be a later setting.
5. **Default voice and rates.** Recommendation: the system's English voice (the system language if it is English, else en-US), Normal at `AVSpeechUtteranceDefaultSpeechRate` (0.5), Slower 0.42 and Faster 0.58. The templates are English, so a non-English system voice would mispronounce them.
