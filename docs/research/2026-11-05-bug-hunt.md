# Correctness bug hunt, 2026-11-05 (work in progress)

Method: read the wire-reachable and file-reachable parsers and state machines
in the Rust crates; for each suspicion write a test. A confirmed bug gets a
`#[ignore = "Bn: ..."]` test in a `bughunt_<crate>.rs` file that fails on the
current code (`cargo test -p <crate> --test bughunt_<crate> -- --ignored`).
No production code is changed.
